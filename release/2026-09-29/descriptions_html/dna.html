Summary

4D DNA Blueprint is the bridge volume between the jammed-substrate physics and all biology volumes. It inherits the substrate from physics and adds one module: the γ ruler (γ = −mean nearest-neighbour stacking ΔG37, SantaLucia), read in two layers (γ LEVEL + A4 SHAPE, plus CpG), with the R19 switch applied to biology and the node atlas. The atlas is the corpus's single source of truth for node identity. The revised headline is "DNA is read 100% (γ level + A4 shape + CpG); building an organism is open [O]". The volume's declared channels are read deterministically. Developmental order, size and timing arise from the independent growth of every object; that is full physics and is not claimed. The former headline correlation corr(γ, GC) = 0.998 is ledgered as an identity. It is intrinsic to the table: random sequence gives 0.9996, so γ's level channel is GC composition in free-energy units. The one independent prediction in the volume, that developmental order follows spinodal(γ), failed: Spearman −0.0865 (n = 47), and γ vs timing ρ = −0.018 (p = 0.99). It is retired. The biology reading rule applies. Measured γ sets each locus's switch threshold (reading). Statements are observation, code output, consistency check or interpretation, and data decides the theory.

Reproduction

The ZIP contains docs/dna/ (the published HTML pages), repro/dna/ (code and data), LEDGER.json and MANIFEST.sha256.

  • Install with pip install -r repro/dna/requirements.txt.
  • Regression: cd repro/dna/repro/dna/_verify && python3 run_regression.py. This should report REGRESSION PASS on 28 canonical γ cases.
  • Per-chapter packages live under repro/dna/repro/dna/<chapter>/. Examples: 09-environment-methylation-layer/cpg_substrate_oe.py and 15-dna-dictionary/build_dictionary.py. The appendix gates are in ax-*/; ax-l-completion-closeout/expected/gate_report.json holds the recorded gate output.
  • GC1 protocol: repro/dna/experiments/GC1_promoter_variant_causal_test/PROTOCOL.json.
  • SEED = 19 is used for corpus-level runs. The _verify regression states its own determinism seed (7).
  • No network access is needed for the shipped checks. Re-fetching promoters from NCBI and running GC1 would need network and data access.
