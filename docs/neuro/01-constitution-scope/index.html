What this paper reads

The object is a single falsifiable chain: ion channel → neuron → metabolic energy → rhythm → the θ–γ working-memory code → memory (write, retrieve, consolidate, allocate) → value, intuition, trauma → multimodal binding → motor output. Each link is a mechanism stated as a true/false prediction. The paper reads what the brain computes, present-tense; it does not read subjective experience, and it does not read the genome (that is the companion DNA paper).

The discipline

Every claim carries a status tag, and the tag is the floor of its evidence: model (the mechanism is coherent and sufficient in a model, not proven in the brain), direction (a model claim whose direction matches real data), causal (a manipulation changes the outcome as predicted), and open (honestly unresolved). Parameters are frozen, derived by rule, then gate-checked; nothing is tuned to the answer. Simulations are deterministic (seed = 7). A model does not certify a model: a mechanism shown to be sufficient in code is never reported as true in the brain.

Inheritance from the γ substrate

The chain is built on the same object as the genome paper: the R19 bistable switch, with a threshold set by stacking stiffness γ. In the brain the switch is the E/I unit, and the readable thing that sets its rhythm is the inhibitory time-constant, not γ — but the discipline, the switch grammar, and the low-frequency reading are inherited. This is why the paper sits on the same jamming branch as the genome paper.

Scope boundary

Two boundaries are drawn up front. Consciousness is out of scope — the access question and the hard problem are open and are deferred to the companion paper, Mind; this chain explains the computation of encoding and behaviour, not the felt quality of experience. The genome is out of scope — γ census and the SET / STATE / DWELL / ENVIRONMENT registers live in the DNA paper. Claims that cite this paper inherit the per-claim status tag; the chain is not citable as a settled whole.

Retired notice

An earlier draft proposed a physical machine — an electromagnetic field "vortex", the axon as an optical fibre guiding light, the EEG as the beat of a carrier wave, energy equated with information, a phase memory written in DNA. These were physically falsified and are retired (see §9). They must not revive as evidence anywhere, under any renaming. The body of this paper carries no retired concept.
