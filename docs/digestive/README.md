# docs/ — CANONICAL HTML (VP-SPEC v1.8)

Per VP-SPEC v1.8 the canonical artifact is the per-title HTML in this directory (C2). It is generated by
`tools/build_docs.py` AFTER the research gates are green (`reports/research_complete.json` all_green and
`PHASE == writing`). Every displayed number is regenerated deterministically by the in-package engine
(C1, 2×sha256 identical) — nothing is hand-entered.

Structure:
- `index.html` — volume hub (`CreativeWorkSeries`), links every section + the cross-volume derivation map.
- `<slug>/index.html` — one page per section (18 sections): answer-first `<p class="answer">` (40–60 words),
  JSON-LD `ScholarlyArticle` + `BreadcrumbList`, canonical link, claim-strip (grade + GitHub repro link +
  DOI status), `vp-card` per cited locked quantity, English body, prev/next nav, footer.
- `_meta.json` — summary card (paper_id, chapters[], grades, word/equation counts, totals).
- `sitemap.xml` — every section + hub URL. `robots.txt` — 7 AI/search bots explicitly allowed.
- `llms.txt` (<5 KB) — authoritative summary block + prioritized links (core / oncology / reproduction).
- `assets/css/site.css` — external stylesheet (no inline CSS/JS anywhere, C4 / spec §6).

Rebuild: `python tools/build_docs.py` (idempotent; byte-identical on re-run).
