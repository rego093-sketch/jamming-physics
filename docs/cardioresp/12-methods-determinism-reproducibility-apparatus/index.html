One deterministic engine, no tuning

Every number on this site is regenerated by one deterministic engine: pinned single-thread linear algebra, a fixed seed, round-before-hash, and sorted-key output. A two-run check yields an identical SHA-256, and the current circulation hash begins 25900a90079acef5….

No constant is chosen to hit a target. The master-gene γ values are measured DNA inputs, the time anchor κ = 0.016327 s/arb is fixed once by the cited resting rate 1.17 Hz, and every other rate is a model rate divided by that one anchor.

A single command, python repro/run_all.py, emerges the organs from γ, confirms the shared oscillator, runs the five-target stress battery and the carcinogen kernel, and then runs eleven reproducibility gates ending in one line: OVERALL: PASS (11/11), drift 0.

File-level reproducibility and provenance

Beyond the engine output, a file-level SHA-256 manifest pins the whole delivered package, so any silent byte-drift in a shipped file is caught. The concept DOI 10.5281/zenodo.20755371 is wired into every section page, the hub, the structured metadata, and the machine-readable index, and a gate fails the build if any surface drifts.

This reproducibility apparatus was inherited from the analgesic-threshold VP volume and is applied here in full; the grade vocabulary and the open-item obstacles are defined in §9.

Offline and wall-clock-free

The engine reproduces with the network socket disabled, so the result depends on nothing outside the package. The build carries no wall-clock: the release date is pinned, so regenerating this site reproduces it byte-for-byte.
