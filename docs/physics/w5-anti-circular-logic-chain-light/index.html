W.5.1 The persuasion assembly order

The mass-energy outputs of this framework are produced in a fixed sequence that uses only one empirical input from outside:

  1. Inputs. (i) Light: a single wavelength λ_ref=632.99nm. (ii) Mathematics: integers (1,2,3,4,5,6), the constant π, and the rectification constants α=2/π, δ=1/π².
  2. Stiffness postulate. Below the structure-formation threshold, the lattice is treated as having unbounded local stiffness. This is what makes c a derived, not assumed, output.
  3. Length. The single empirical λ_ref fixes the realization length a and the canonical cell.
  4. Frequency. The canonical event rate ν_p,can=3π⁴≈ 292.23s⁻¹ is fixed by the n-fold rectification law (LOCK-NU-N, §8.0.5); the length-anchored 292.24 from the Sₚ/core geometry agrees to +61 ppm (cross-check).
  5. Time. Δ t follows from a/c_ref.
  6. Mass. mₚ=hc/λ_C, mₚ/mₑ=6π⁵, m_H=U_lat/(5π).

The crucial property: only step 3 uses an empirical input. Steps 4–6 do not introduce any new free parameter. This is the formal sense in which the framework is "single-anchor."

W.5.2 The circular suspicion is legitimate (we acknowledge it)

A trained reviewer immediately objects: "You used λ_ref=632.99nm to set the lattice. Then c comes back out. This is circular." The suspicion is well-formed and we take it seriously. The full refutation has two prongs.

W.5.3 Prong A — Dimensionless results do not consume the anchor

Many of the central claims are dimensionless ratios:

For each of these, multiplying λ_ref by any non-zero factor leaves the prediction unchanged. The anchor enters only when an absolute mass or length is asked for. The dimensionless outputs are therefore anchor-free: circularity, even if real, cannot account for these. (Note: αₑₘ⁻¹≈137.036 is not included here — it is an open input taken from measurement, not a derived output; see §14.5.)

W.5.4 Prong B — Length-in, mass-out is not a tautology

The objection assumes that "length in ⇒ length out" is an identity. It is not, because in steps 5–6 we extract a mass:

h and c are universal constants; the only role of λ_ref is to set the scale a. The number 1958.7 GeV (for U_lat=hc/a) is then divided by the pure geometric factor 5π, which has no empirical input. Hitting 125.20 GeV after that chain to within 0.40% is therefore not a tautological closure; it is a non-trivial coincidence between the measured wavelength of a helium–neon laser and the measured Higgs mass, mediated by a six-line algebraic derivation containing no free parameters.

A genuine circularity would let any choice of λ_ref self-cancel; here, changing λ_ref by 5% moves m_H by 5% to a value the measurement excludes. The closure is therefore predictive, not circular.

W.5.5 What a reviewer should still want

We do not claim this discharges every concern. The remaining open items are: (i) the unbounded-stiffness postulate cannot be measured directly in this framework; (ii) the framework retrodicts known constants but has not yet predicted an unmeasured one to high precision (narrow-sense prediction); (iii) the gravity absolute value 9.80665 m/s² enters by back-substitution (see §17.4). These are flagged honestly and are the targets of future work, not buried.
