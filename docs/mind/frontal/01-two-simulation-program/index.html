Two simulations, one end condition

This program is two long-term simulations that close together. Simulation 1 — mind_vp v1.57 — is the heavy, successful run: a physics-grounded 12-node ephaptic engine that emerges brain organs from measured 4D-DNA master genes, then builds brainwaves, memory, inter-organ coordination, the embodied loop, global state and affect, plus a 28-module clinical atlas. It was built under strict no-tuning discipline, its honest negatives were preserved, and the consciousness firewall held. It is frozen and read-only.

Simulation 2 — vp_frontal — is additive. It gives the cortex the internal microstructure Sim 1 left as a single undifferentiated node, adds the second physical coupling channel Sim 1 omitted, and operationalizes the cognition / consciousness-access / body framework. The whole project closes only when both simulations are complete.

The frozen kernel and why additions do not break it

The discipline that makes Sim 2 possible is a single observation: a node of the frozen 12-organ kernel can carry a rich internal model without changing the kernel. The hippocampus is the precedent — a 120-cell autoassociator already sits behind one node of the frozen engine, and the engine is unchanged by it. Cortical microstructure is added the same additive way, so the M9 anchor R = 0.38961455156044245 stays bit-identical.

This corrected an earlier claim. The first frontal probe had argued that a v2 substrate must break the frozen engine; the hippocampus precedent shows it need not. v2 additions are new modules or a clearly-provenanced branch, never edits to vp_mind_engine.py.

Six governing principles, inherited verbatim

No tuning. No value is set arbitrarily. Every quantity emerges from measured gene parameters (4D-DNA γ), physics constants (Maxwell's equations, the ephaptic coupling κ), or cited public measurements graded [L] with provenance. Each module carries new_tuned_constants = 0.

Frozen engine, read-only. The engine file is never modified, and the M9 anchor must keep reproducing bit-for-bit on the unchanged kernel.

Grading. [V] is a verified mechanism (sign-stable, robust); [L] is locked to a cited or measured input (the absolute scale may itself be [O]); [O] is open, or an honest negative. Function is modeled; experience is not.

Anti-tuning. Never trust a single operating point. Sweep duration, seed, perturbation node, and coupling, and believe a claim only if it is sign-stable across the sweep. This is the lesson the first frontal probe paid for: a clean signal at one operating point flipped under a duration sweep.

No circular read-outs. A read-out must not be a direct function of the thing being perturbed. (In Sim 2, a cortico-thalamic transmission “deficit” was circular — the read-out was the severed edge — and was demoted to a construction check.)

The Stress Principle. The core long-term rule: every hypothesis is stress-tested to destruction. If it collapses under stress, the collapse is recorded and accepted, and the affected line restarts from the beginning with the collapse built in.

The Stress Principle in practice

Sim 1 was built this way, and its honest negatives — negligible temporal holding, the leucotomy sign-flip, the strict-access PCI negative — are preserved collapses, not failures. Refinement means surviving the stress, never avoiding it. In Sim 2 each of the four fillable gaps received a stress test explicitly designed to break it; the grade each gap carries is the verdict of that test, and the parts that collapsed (a peak sitting above the measured coupling, an unconscious ordering that flattens to one scalar) are recorded as standing [O] residuals rather than smoothed over.

The correction that opened Sim 2

The first frontal probe (F1) reported that cortical temporal holding is negligible and that the signal sign-flips. That negative was diagnosed as an under-emergence artifact: the probe loaded only a static ephaptic-kernel snapshot and ran a bare coherence-recovery test — it asked a working-memory question with the working-memory machinery (theta–gamma, hippocampal pattern dynamics) removed. With that machinery present, the emerged memory reports a real working memory (capacity 6.125 items, completion 1.0), while the bare probe reported cortical holding ≈ −0.0001. Restoring the emergence flipped the false negative, and the additive cortical micro-model that followed became Gap 2.
