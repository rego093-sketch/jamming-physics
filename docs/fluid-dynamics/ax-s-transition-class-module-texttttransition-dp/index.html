The transition-class module (transition_dp.py)

Implements the G-SOC rules as a synchronous 1D lattice with pseudogap-drawn shear reserves; locates the critical point by slope-matched bisection and curvature-minimised refinement; measures decay, spreading, survival, lifetime and activity-correlation exponents against the directed-percolation values; and runs the SOC-driven avalanche variant.
