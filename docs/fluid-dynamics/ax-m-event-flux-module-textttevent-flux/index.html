The event-flux module (event_flux.py)

Tests Pillar IV's mechanism gate in 1D Burgers (ledger row IV/flux): the viscous dissipation equals the shock defect (Δ u)³/12 (the event flux), ν-independently, and the Duchon–Robert inter-scale flux is ∼100% concentrated at the shock—the event carries the inertial flux to the dissipation scale. Full source is shipped as event_flux.py.
