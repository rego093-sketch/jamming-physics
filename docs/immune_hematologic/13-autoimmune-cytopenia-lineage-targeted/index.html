Lineage-targeted autoimmune cytopenia

When the autoreactive clone's target is a produced blood lineage, the disease reads out on a cell count. While the clone is latched ON it raises the clearance of the lineage, so the produced output COLLAPSES from its healthy level to a cytopenic floor (measured 1.00 → 0.14 of healthy) — and the collapse is gated by the same +spinodal break, a sub-spinodal insult leaving the output healthy (0.93) and a supra-spinodal one collapsing it (0.14). The treatment classes separate exactly as before: a transient re-tolerization restores the output DURABLY (to 96% of healthy) while a sub-critical suppressor only contains the attack and the output RE-COLLAPSES on withdrawal (to 14%). Lineage SUPPORT alone is insufficient — the ongoing attack clears the supported output (14%) — but the COMBINATION of re-tolerization plus support reaches the SAME healthy destination FASTER than the cure alone (time-to-recovery 377 vs 1844 steps): the cure sets the destination, support only sets the rate.

Part of the disease/treatment axis: a pathological immune state is a latched basin, and the durable class of intervention moves the system across the saddle-node rather than only holding the drive down, which relapses on withdrawal.
