Cases by register

Every verified case re-homed under one primary register with its measured anchor and status — zero re-interpretation.

Each verified case is assigned its primary register and measured anchor, so every claim has a home and a number: MATERIAL (γ census, UCP1 warm=cold), SET (OTX counts), STATE (white grape, snake ZRS), DWELL (mouse/elephant, salamander), ENVIRONMENT (CpG handles, TSD). No case is re-interpreted.

Cross-register cases carry a primary register plus an explicit cross-reference (UCP1 → ENVIRONMENT for endothermy; snake ZRS → MATERIAL for γ-blindness; salamander → ENVIRONMENT for the trigger). The kit's wider cases — plant ripening, germination, the 18-organ atlas, the disease program — map by the same logic (mostly STATE and DWELL within a shared SET) and are not re-interpreted here.
