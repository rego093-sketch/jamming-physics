## 2. 가장 중요한 개선점 Top 7 (헤드라인 신뢰도에 미치는 영향 순)

### ① 6π⁵ 헤드라인: [F] 등급, 오차예산 부재, 반증 면제 (이슈 1, 27, 40, 48)

**무엇이 문제인가.** mₚ/mₑ = 6π⁵는 여섯 곳에서 [F] "forced"로 표기된다. W.0 스코어카드, RF forced 목록, §13.5 카드, 전 장 헤더 카드, §8.0.6(C), `vp_locks.csv`이다. 잔차는 −18.82 ppm인데 이론오차 예산은 어디에도 없다. 정확한 항등식으로 읽으면 CODATA 2022 대비 −1.08×10⁶σ로 배제된다(2018 값 기준으로는 −3.1×10⁵σ).

**근거.**
- 볼륨 내부의 규칙 충돌:
  - Prologue §0.1.1은 [H]를 "closures, idealizations, approximations, model choices"로 정의하고 "retroactively promoting [H] to [F] is not allowed"라고 쓴다. 그런데 BT는 이 비가 "upgraded from [H] to [F]"되었다고 쓴다.
  - §1.10(i)는 잔차를 "not a legitimate falsifier"로 규정한다. 그 결과 헤드라인은 어떤 측정으로도 반증되지 않는다. 이는 §1.4의 "tolerances … fixed in gate_lock before results" 규칙과도 충돌한다.
- 실패할 수 없는 자가검증:
  - §1.8.3의 유일한 경험적 assert는 `abs(mp_me_measured/pi**5 - 6) < 2e-4`이다. 이 허용치는 33 ppm으로, 이미 알려진 잔차의 1.77배다. 따라서 "if a reader's run prints anything other than ALL PASS, the framework is wrong"은 사실상 실패하지 않는다.
  - RF의 40줄 키스톤 박스는 강성도 파속도 계산하지 않는다. 출력은 U, 힘, 접촉수뿐이다. φ는 R을 스윕해 직접 설정되고, 출력된 φ_jam은 손으로 정한 onset 규칙에 따라 0.616에서 0.636 사이로 달라진다.
- 선행 연구와 수용: Lenz(1951)는 Prologue에만 인용되고 §8.0.5와 §13.5에는 빠져 있다. VH v0.2.1을 보면 LOCK-NU-N은 6π⁵가 이미 알려진 뒤 채택되었다. 연속 매개변수가 없으므로 "적합(fitted)"이라는 비판은 과하다. 정확한 표현은 "수용(accommodation)"이다.

**왜 중요한가.** root 볼륨의 대표 수치가 볼륨 자신의 정의를 어긴 채 등급화되어 있고, 반증 규칙이 그 수치를 데이터로부터 면제한다. 한편 일치 자체는 진짜로 드물다. n·π^k 족(n≤12, k≤8)에서 18.8 ppm 이내로 우연히 맞을 확률은 P ≈ 4×10⁻⁴이다. 결함은 산술이 아니라 등급과 반증 가능성에 있다.

**수정.**
1. 등급을 둘로 나눈다. "[F] 수학: MAP-1/2가 주어지면 2π·3π⁴ = 6π⁵"와 "[H] 물리적 동일시: mₚ/mₑ = 6π⁵"로 쓰고, 여섯 곳 모두에 반영한다.
2. gate_lock에 이론오차 예산을 사전등록한다(예: tree-level이며 1차 보정의 크기와 부호를 명시). pull은 그 단위로 보고한다.
3. §1.10(i)를 "사전등록 예산 ε를 넘는 잔차는 동일시의 반증자"로 고친다.
4. §1.8.3을 "산술 일관성 검사"로 개명하고 ALL PASS 문장을 삭제한다. SP의 "All three statements are exact"도 삭제한다.
5. §8.0.5와 §13.5에 Lenz 인용과 LEE 추정을 붙인다(n·π^k 족 P ≈ 4×10⁻⁴, (p/q)·π^k 족 ≈ 3×10⁻³).

### ② "강제" 사슬 속의 숨은 이산 선택 (이슈 9, 15, 18, 37, 56, 57, 58)

"no free slot"이라는 주장은 선언되지 않은 이산 선택 여러 개에 기대고 있다.

- **지수 n−1의 출처가 둘이다.**
  - LOCK-NU-N 헤더와 §8.0.5(II)는 게이지 보조정리 dim(Rⁿ/span 1)를 출처로 든다.
  - §8.0.6(A)–(B)는 C₃ 폐합이 "removes no rectification"(⟨Wₙ⟩ = δⁿ)이라 하고, 단일 노즐 δ를 출처로 든다.
  - 두 메커니즘이 모두 작용하면 6π³ = 186.04, 둘 다 없으면 6π⁷ = 18,121.8이다. 3π⁴를 고르는 것은 [MAP-2] 짝짓기다.
  - [MAP-2]는 1/δ를 증폭기로 쓰는데, 이는 §5.4의 "Role restriction"과 충돌한다. 인용처인 §9.2에는 "resistance = inverse survival"이라는 내용이 없다.
  - ν₁ = 1이라는 "nontrivial check"는 ν_e := 1 정규화 때문에 자명하게 성립한다.
  - §8.0.6(D)는 격리된 §14.5.3(COINCIDENCE/NON-EVIDENCE)을 근거로 인용한다.
- **n = 3.** ch07의 "not a choice"는 analysis_lock에서 고른 2-D 평면 안에서만 참이다. 3-D의 최소 positive spanning set은 4개이고, ch06 [C-82/7-08]도 이를 인정한다. 참고로 n = 2이면 124.03, n = 4이면 24,162.3이다.
- **S¹이냐 S²냐.** α = 2/π와 δ = 1/π²는 원(S¹) 위의 평균이다. 3-D 등방이면 α = 1/2, δ = 1/16, α/δ = 8이 되고, R_p는 0.661 fm(−21.5%)이 된다. §6.2는 4πR² 희석(3-D)과 [0, 2π) 정류(S¹)를 섞어 쓴다.
- **R_p/L_q = 2/π.** 균형식은 R/L = B/A이고, 2/π라는 값은 α를 어느 항에 두느냐로 결정된다. ch06과 ch11은 이 배치에서 서로 모순된다. 다른 배치를 택하면 1.3214, 2.0757, 0.5355 fm이 나온다. 전역 안정성(F′ = −9.563)은 1-D 흐름에서는 자명한 성질이다.
- **5π.** π는 원판 넓이를 반지름 제곱으로 나눈 값이고, 인수 4는 (a/2)² 정규화에서 온다. L_ref = a로 잡으면 498.8 GeV가 된다. 5 = 6−1은 u_f의 정의가 정해지지 않은 상태에서만 성립한다. BT는 5π를 step 2([H])에 두는데, RF와 §1.8.1은 "Forced / Geometry (no DOF)"로 분류한다.

**수정.**
1. 반사실 표를 게시한다. 지수 출처(ν₃ ∈ {3, 3π², 3π⁴, 3π⁶}), S¹/S², n, α 배치, L_ref와 h/ħ 선택별로 결과가 어떻게 달라지는지 보인다.
2. 등급을 조정한다. ν_n과 6π⁵는 "[F] conditional on MAP-2", n = 3은 [L], r_p = 4ħ/(m_p c)와 5π는 [H]로 둔다.
3. ħ 형식을 병기한다(m_H = (2/5)ħc/a). Haramein(2013)을 선행 연구로 인용한다.
4. 하류의 [A] 9개(U0–U4, S1–S2, M1)를 공리표 하나에 등록하고, 결과×가정 행렬을 추가한다.

### ③ 빛의 정체성: 종파 c² = B/ρ와 횡파 Maxwell의 모순 (이슈 7, 14, 41, 42)

**무엇이 문제인가.**
- SP S2.3([V])과 §11.6.1은 "The transverse wave dies; one longitudinal speed survives, c²=B/ρ"라고 쓴다. 허브 제목과 W.0([V])는 이것을 빛의 속도와 동일시한다.
- 반면 §14는 빛을 "the transverse, propagating part"라 하고 "photons carry helicity ±1"이라 쓰며, source-free Maxwell을 [F]로 등급화한다.
- G → 0인 매질에서 횡파 속도는 √(G/ρ) → 0이다. 남는 모드 u = ∇φ는 헬리시티 0이다.
- §10.9는 세 번째 그림을 제시한다. 빛은 종성분이 필요한 횡진동이고 γ선은 "quasi-longitudinal"이라는 것이다.

**근거.**
- Born 모듈러스로 구제하려 해도 G = 3B/5가 되어 c_T² = 0.6B/ρ, c_L² = 1.8B/ρ이다. 어느 쪽도 B/ρ가 아니다.
- §15.5.1은 8π를 "usual electromagnetic prefactors"로 가져온다. 편광이 1개라면 σ_SB는 절반이 되고, Quinn–Martin 측정과 3,730σ 차이가 난다.
- chemistry 권 안에서도 ch.1(종파)과 ch.2(회전 횡파)가 다르다. chemistry EM.12.4는 이 섹터를 [O]로 두는데 physics §14.0.6은 [F]로 둔다.
- 공리와 검증 기판이 맞지 않는다.
  - [V]의 근거는 겹침이 있는 조화 소프트 구를 FIRE로 최소화한 결과다. 그런데 [A-1]은 겹친 배치를 "inadmissible"로 규정하고, §3.1.5는 closure 선언 없이 거리 함수 쌍퍼텐셜을 쓰는 것을 금지한다.
  - B_Born은 N = 256에서 1024로 가는 동안 1.56배 변해 수렴하지 않았다.
- Coulomb 섹터의 부호와 장 정의 문제.
  - like-repel 부호는 Poisson 식을 강제 제약으로 둘 때만 나온다. 본문이 명시한 "the medium relaxes it"에서 나오는 부호는 like-attract다.
  - E는 두 가지로 정의된다(§14.0.6에서는 변위, §14.0.6b에서는 속도).

**수정.**
1. 헤드라인을 둘로 나눈다.
   - (a) [V]: "z = 2d에서 G_relaxed → 0이고 B는 유한하므로, 유일한 전파 음향 가지는 종파다."
   - (b) [O]: "이 모드가 빛이다." 장애물로 "G = 0 매질에는 횡파가 없고, 빛은 헬리시티 ±1 두 상태만 가진다"를 적는다.
   - (b)가 닫힐 때까지 허브 제목을 바꾸고, §14.0.6을 [H]로 내린다.
2. G-POL 게이트를 사전등록한다(작은 q에서의 가지 수와 각 가지의 횡성분 비율). 현재 스파인은 FAIL을 예측하므로, 결과가 나오면 "반증 = 발견"으로 기록한다.
3. 건설적 경로를 검토한다. Cosserat/MacCullagh 회전탄성 매질에서는 c² = κ/I, 횡편광 2개가 나오고 종성분은 Coulomb 제약이 된다.
4. 접촉 법칙을 closure로 선언한다: U = (k/2)δ², 모듈러스는 k 단위로 보고.

### ④ "단일 앵커, DOF = 1"의 실패와 Higgs의 N 의존 (이슈 3, 8, 23, 35, 38)

**무엇이 문제인가.** 전 장의 칩은 "λ_anchor … Single empirical anchor (DOF = 1); the only measured length input … [F] forced"라 쓰고, §1.8.1은 "exactly one"이라 쓴다. 실제 입력은 다음과 같다.
- 측정 앵커 두 개:
  - λ_ref → a → U_lat, m_H
  - CODATA mₑ → D = 2λ_C,e → r_p, m_p, χ, τ_q, T_e
- 선언된 값: N = 10¹², Δt(유효숫자 3자리), g₀
- 세지 않은 이산 선택들

두 앵커를 잇는 유일한 다리 D = 2πλ/A는 4.515 pm로, 필요한 값보다 7.0% 작다. W.6 스스로 "not a parameter-free derivation of 4.85 pm"라고 쓴다. §14.0.4의 "mₑ = 2hc/D … −0.03%"는 D ≡ 2λ_C,e이므로 항등식이다.

**Higgs.** m_H = hcN/(5πλ_ref)이다.
- N = 10¹¹이면 12.47 GeV, 10¹³이면 1,247 GeV다. 532 nm 선을 쓰면 148.37 GeV(+19.0%)다.
- N = 10¹²을 고른 물리적 근거는 본문 어디에도 없다.
- §1.8.2의 N-불변 표는 m_H/U_lat = 1/(5π)만 검사하는데, 이것은 정의상 항등식이다. 따라서 "no dimensionless output depends on it"은 거짓이다. m_H/m_p는 N에 비례하기 때문이다.
- −0.40% 잔차는 PDG 125.20 ± 0.11 GeV 대비 −4.6σ인데, σ 값은 어디에도 적혀 있지 않다. 출처 표기 "CODATA/PDG 2024"도 틀렸다. CODATA는 Higgs 질량을 싣지 않는다.

**헤드라인 과장.** RF의 "reproduces … QED, GR, and the Standard Model", ML의 "a dozen constants from one anchor", 홈페이지의 "0 fitted parameters"는 등급화된 내용을 넘어선다. 독립적인 경험 비교는 세 개(m_p/m_e, r_p, m_H)뿐이다.

**수정.**
1. §1.8.1을 완전한 입력 원장으로 바꾼다. 연속 측정 입력, 선언된 값, 이산 선택을 나열하고, 각각을 어느 출력이 소비하는지 적는다.
2. 헤드라인을 "무차원 π 형식은 앵커를 쓰지 않는다. 차원 있는 출력은 앵커 두 개와 선언된 N, Δt를 쓴다"로 고친다. λ_anchor와 D의 칩은 [L]로 바꾼다.
3. m_H는 "(λ_HeNe(I₂), N = 10¹², 5π) 조건부 일치"라는 단서와 함께 [H]로 둔다. A3 집계에서는 빼거나 조건부로 표기한다.
4. 모든 잔차에 σ-pull을 병기한다.

### ⑤ 순환 고리: Δt↔A↔c, r_p "+61 ppm", T_e ≈ 1 s (이슈 2, 5, 6, 31, 33)

**Δt, A, c.**
- §11.3 [D-11.3-3]의 80자리 A는 c·(1.86×10⁻²¹ s)/a와 80자리 전부 일치한다. 그러므로 "cΔt/a=A closes exactly"와 "derived result"는 같은 값을 왕복한 것일 뿐이다. repro 도구 스스로 이 값을 "⚠placeholder"로 표시한다.
- c_env = c_ref는 [D-11.3-3]과 §11.3.3의 정의 때문에 성립하는 단위 항등식이다. 그런데 §1.9 A1은 이를 "Resolved [F] … it shows it"로 쓴다. 이는 볼륨 자신이 금지한 FAIL-CREF-PREDICT에 해당한다.
- λ_ref는 c/f_HeNe(CIPM 값)와 20자리까지 일치한다. 따라서 Δt = A/(N·f)이고, 시간 단위는 Cs 기준의 외부 주파수에서 물려받은 것이다.
- A_geo "0.16%" 일치는 공개된 수치로 재현되지 않는다(평균 기준 +0.35%, 중앙값 기준 −16%). 이 일치를 확인한다는 verify_A_scaling.py도 저장소에 없다.

**r_p.**
- §6.3.3에서 "locked"된 λ_C = 1.3213538700998668 fm는 (π/2) × 0.8412다. h/(m_p c)가 아니며, 그보다 −42.37 ppm 작다.
- "+61 ppm cross-check"는 6π⁵ 잔차 18.82 ppm과 4자리 반올림 오차 42.37 ppm을 더한 값이다. 그런데 SSOT는 이것을 "독립#2"라 부르고, gate.py는 61.2 ± 0.5 ppm을 강제한다.
- 유일한 외부 검사는 D/(6π⁶) = 0.84125 fm를 측정값과 비교하는 것이다. CODATA 2022 값 0.84075(64) fm 대비 +0.78σ다. 그런데 본문은 CODATA 2018 값(0.8414 fm)만 인용한다.

**T_e와 ν의 단위.**
- ν_n은 무차원인데 §7.2.1은 "[s⁻¹]"로 잠근다.
- canonical second를 SI second와 동일시하는 판정을 맡은 G-E1S에는 판정 규칙도 판정 결과도 없다.
- T_e = (6/5)(D/a)³Δt = 1.0058 s는 Δt에 선형이다. A를 고정하면 N²에 비례하므로, "Tₑ∝N² scaling invariance"라는 표현은 틀렸다(불변이 아니라 의존이다).
- 일관된 A 하나를 쓰면 T_e는 0.81–0.98 s다. 1.0056 s는 셀 측도 세 가지 중 하나를 고른 결과다.
- D의 "0.04%" 일치도 분포에서 가장 잘 맞는 사태 하나를 고른 값이다. 분포의 중앙값은 4.96 pm로, +2.2% 차이다.

**수정.**
1. §11.3을 "Δt의 실현(선언된 입력)"으로 개명하고 80자리 A를 삭제한다. A는 A_D, A_Δt, A_SOC로 기호를 나눈다.
2. A1을 "SI에서 c_env = c_ref는 단위 항등식이다. 비자명한 내용은 격자 단위의 종파 속도 [V]다"로 다시 등급화한다.
3. A3에서 A_geo와 T_e를 빼고 결합 확률을 다시 계산한다.
4. r_p 잠금 값을 삭제하거나 8자리 이상으로 늘린다. 물리적 잔차는 R1 하나만 남기고, 61.2 ppm 게이트는 삭제하고, 비교 기준을 CODATA 2022로 바꾼다.
5. ν는 무차원으로 표기한다. T_e는 (λ_ref, N, g₀, Δt) 조건부 [O]로 둔다.

### ⑥ 중력 섹터: EP 위반, "강(river)" 항등식, cap 불일치 (이슈 10, 11, 13, 16, 19, 45, 47)

**EP(약한 등가원리) 위반.**
- §14.0.4는 중력원 Q를 소멸률(ν_p = 3π⁴, ν_e = 1)로 둔다. §17.4.4(ii)는 시험 물체에 걸리는 힘을 F = Q_t·p₁로 둔다.
- 둘을 합치면 전자의 Q/m이 핵자보다 2π배 크다. 그러면 η(Ti, Pt) ≈ 1.7×10⁻⁴(전자 항만)에서 ~1.1×10⁻³가 되어, MICROSCOPE 한계를 10¹⁰–10¹¹배 넘는다.
- 그런데 등급이 제각각이다. Result 5, App G, RF는 "EP derived"[F]라 쓰고, §18.10과 W.0는 [F?]로 둔다.

**G-RIVER 항등식.**
- G-RIVER는 v_river := √(2GM/r)로 정의한 뒤 `fr == fs`를 검사한다. 정의상 항상 참인 대수 항등식이다.
- 이는 Painlevé–Gullstrand와 Hamilton–Lisle(2008)의 river 모형인데 인용되지 않았다. §18.0은 "No external relativistic postulate"라고 쓴다.
- 매질의 실제 1/r² 유동을 §18.0의 규칙에 넣으면 시간지연이 r⁻⁴로 변하고 크기가 120–1,100배가 되어, Gravity Probe A와 Galileo-5/6 결과와 충돌한다.
- §18.8의 "orbits, light bending, GW … exact Schwarzschild"는 g_tt만 유도된 상태에서 한 주장이다.
- √(1−v²/c²)의 [F] 등급은 숨은 가정 d(v) = 1에 기댄다. d = 0.8, v = 0.6c로 두면 시간지연이 0이 된다.

**cap과 four-wall theorem.**
- App G는 Ψ_yield := 9.80665/c²(정의)와 "지구가 항복점에 있다"는 해석을 [F]로 둔다. §18.8은 α ≳ 0.82에서 contact-only 해석을 택한다. 두 해석은 양립하지 않는다.
- Prologue Misreading 4는 "forbids GM/R²"라고 쓰는데, §17.4.4는 "reproduces g=GM/R² at machine precision"이라고 쓴다.
- 극지 중력 9.832 m/s²는 g*보다 크다.
- "four-wall theorem"은 [F] "proven no-go", "resource bound", [O]라는 세 가지 등급으로 불린다. Wall 3의 "10⁰~10²" 전제는 캐넌 자신이 쓰는 6π⁵ ≈ 10^3.3, A ≈ 8.2×10⁵과 모순된다.

**수정.**
1. 두 비율을 분리한다(ν_ann := m/(2πm_e)). EP 등급은 [F?]로 통일하고, G-EP 게이트(MICROSCOPE, Eöt-Wash, LLR)를 등록한다.
2. G-RIVER는 [H]로 내리고 선행 연구를 인용한다. G-ONEFIELD를 등록한다.
3. §18.8 문구를 g_tt로 한정한다. PN과 GW 섹터는 cosmology 권 Ch10–11의 [O] 항목으로 연결한다.
4. App G를 α 매개화 기준으로 다시 쓴다. four-wall theorem은 "장애물 열거 [O]"로 부른다.

## 6. 유지할 강점

- 잔차를 숨기지 않는다(−18.8 ppm, −0.40%). 5π를 4.98π로 옮기는 식의 계수 이동을 거부한다.
- α_em 닫힌 식을 COINCIDENCE/NON-EVIDENCE로 강등했고, 그 근거(4π는 단위 인공물, α의 러닝, 경쟁 식의 존재)가 모범적이다. 89/82 Coulomb 과적합도 철회했다.
- 중력 섹터에서 정직한 음성 결과(G-CAP-DEPART)를 냈다.
- W.6의 honest-reading 노트(A ∝ 1/g₀, D는 분포)와 v34 규칙(재실행할 수 없는 증거는 불인정)이 있다.
- RF의 Layer A(수학)와 Layer B(물리적 동일시) 구분은 올바른 틀이다. 이것을 등급에 일관되게 적용하면 대부분의 등급 지적이 해소된다.
- 두 개의 정밀한 무차원 일치가 핵심 경험 내용으로 남는다. 6π⁵(−18.8 ppm, P ~ 10⁻³)과 r_p ≈ 4ħ/(m_p c)(CODATA 2022 대비 +0.06%, 1σ 이내)이다.
- 스파인 S2.4는 교과서적인 등방정(isostatic) 재밍 결과를 관측량 다섯 개로 재현한다.
- `vp_numeric_ssot.py`는 표시된 수치를 결정론적으로 재생성하고, 스스로 Δt를 placeholder로 표시한다. §1.1.2의 튜닝 모드 분류와 FAIL 라벨 체계도 유용하다.
- 닫힌 식 산술은 재계산한 범위에서 모두 일치했다(3π⁴, U_lat, m_H, 격자 점 수 19/27/81/123 등).

## 7. 검증에서 기각된 지적

독립 항목으로 통째 기각된 지적은 없었다. 아래는 검증 과정에서 **부분적으로 기각되거나 약화된 하위 주장**이다.

- **Higgs 5π의 −4.6σ를 "[F] 정확식의 실패"로 본 것.** 본문은 이미 −0.40% 폐쇄를 [H]로 두고 있다. 남는 문제는 RF와 §1.8.1의 표기 불일치다.
- **"6π⁵는 사후 적합"이라는 주장.** 연속 매개변수가 없으므로 "수용"이 정확하다. Lenz는 Prologue에서 인용된다.
- **"코퍼스에 분산 분석이 전혀 없다"는 주장.** cosmology 권이 Fermi GRB 090510과의 충돌을 [O]로 다룬다. physics 권으로 이관되지 않았을 뿐이다.
- **GRB 한계가 τ_relax를 구속한다는 주장.** 과녁이 틀렸다(해당 보정은 ~10⁻⁴³). 실제 구속은 우주론적 거리에서 빛이 살아남는다는 사실에서 나오는 τ ≳ 10¹⁷ s다.
- **태양과 백색왜성의 log g가 cap을 반증한다는 주장.** G.4(ii)가 유체 천체를 cap이 없는 채널로 보낸다. 다만 그 결과 태양계 안에서는 cap을 시험할 수 없게 된다.
- **지표 위 free-air 기울기가 hard clip을 반증한다는 주장.** 아니다.
- **"Rewriting in C gains <10²"가 렌더링 오류라는 주장.** 정상적으로 렌더된다. **JSON-LD headline에 등급이 들어 있다는 주장.** 아니다("Force").
- **"c² = B/ρ [V] 대 [O] 횡파" 배지 충돌.** ch14는 [O]가 아니라 [H]다.
- **"dna도 R19를 쓰지 않는다"는 주장.** 거짓이다. seams.json의 physics 인용은 R19가 아니라 재밍 기판을 가리킨다.
- **α_em "두 가지 공식".** δ와 δ_proj의 표기 실수다.
- **"A2가 φ = 1을 주장한다"는 지적.** [A-2]는 존재론적 공리다.
- **physics의 c² = B/ρ [V]가 0.06% 1-D 사슬에 의존한다는 주장.** 아니다. 근거는 3-D Maloney–Lemaître 계산이다.
- **"모델 자신의 rms가 16–22% 작다"는 주장.** 모델은 전하밀도를 지정하지 않는다. 이 수치는 균일 분포를 가정할 때만 나온다.
- **Bell 위반이 "구조적으로 배제"된다는 주장.** 측정 독립성과 fair sampling을 유지할 때에만 배제된다.
- **J가 6/π만큼 과계수라는 지적.** 정의상 규약이다.
- **체적 결합으로 η ~ O(1)이 나온다는 주장.** 틀의 결합은 F = Q_t·p₁이다.
- **r_p 재분류가 "기록 없는 LOCK 편집"이라는 지적.** VH와 §8.0.5에 버전으로 기록되어 있다.

### 8.1 보고서 판단을 수정하는 항목
- **A의 N^(−1/3) 감소 (이슈 33).** 이것은 예측이 아니라 기하학적 필연이다. 상자를 고정하고 입자를 늘리면 간격이 줄기 때문이다. A는 척도를 운반하는 무차원수이므로 분해능에 따라 변하는 것이 정상이다. "parameter-free가 아니다"라는 비판은 철회한다. 본문의 "predicted"는 "geometrically necessary"로 바꾸는 것을 권한다.
- **순환논리.** 보고서는 헤드라인 전체가 순환이라고 한 것이 아니다. A 80자리, r_p +61 ppm, G-RIVER 세 검사를 증거 목록에서 빼라는 뜻이었다. m_H는 순환이 아니다(8.2 참조).
- **등가원리 (이슈 10).** 저자가 의도한 그림은 시험 물체가 유입 흐름에 실려 떨어지는 것이고, 이 그림에서는 등가원리가 저절로 성립한다. 따라서 문제는 이론이 아니라 §17.4.4(ii)의 식 `F = Q_t·p₁`이 그 그림과 다르다는 점이다. 식을 고치면 해소된다.

### 8.2 유지되는 항목 (저자 확인 포함)
- **full 물리 계산과 9.8 m/s² (이슈 13, 19).** 저자 스스로 full 물리 계산 기록은 증거가 되지 않는다고 확인했다. 따라서 cap과 절대 g는 [O]다. App G의 `Ψ_yield := 9.80665/c²`에 붙은 [F]는 내려야 한다.
- **N = 10¹² (이슈 8).** 저자에 따르면 N은 계산을 위한 임의의 격자 크기다. 그런데 m_H = hcN/(5πλ)이므로 m_H도 N에 비례한다. 따라서 124.7 GeV 일치는 N = 10¹²을 고른 것에 조건부이며, 헤드라인 증거로 쓰려면 N을 정하는 근거가 필요하다.

### 8.3 코드로 확인한 사실
- **λ의 역할.** λ는 입력 상수다(`LAMBDA_633 = 632.991e-9`). `ellrot_verify.py` 주석도 "물리 입력은 lambda_light 하나뿐"이라고 적는다. A는 파장 없이 격자에서만 계산된다(`wavelength_jamming.py`).
- **532 nm 채널.** 같은 A로 나누기만 한다(`jamming_rotation_485pm_study.py`). A를 고정하면 D가 λ에 비례하게 된다(633 nm → 4.97 pm, 532 nm → 4.18 pm). 두 파장 비율 (λ/D)₆₃₃/(λ/D)₅₃₂ = 633/532는 D를 고정하면 산술적으로 항상 성립하므로 증거가 아니다.
- **RCROSS.** `dt_633.txt`와 `dt_532.txt`가 모두 같은 잠금값 1.86×10⁻²¹을 복사한다. 그래서 dev = 0, PASS가 되며, 이 게이트는 실패할 수 없다.
- **A 크기.** `wavelength_jamming.py`는 `A_paper = 8.0e5  # illustrative`를 하드코딩한다. bare percolation에서는 A가 퇴화한다.
- **App M (이슈 29, 35).** `verify_appendix_M.py`는 철회된 r_e = (D/2)δ를 써서 m_e = 5.042 MeV를 낸다. 이는 정답(0.511 MeV)의 π²배다. 그런데도 I_e = m_e·S/U_lat ≡ 1이 정의상 성립하므로 PASS가 나온다. 스크립트 수정이 필요하다.
- **χ 민감도 (이슈 4).** D를 ±0.03% 스캔하면 χ의 최대 변화는 0.16°(633 nm)와 0.17°(532 nm)다. 본문의 "0.03% ⇒ >1°"는 약 6배 과장이다. 변화는 m = ⌈λ/D⌉의 정수 점프에서 온다.

## 9. 6π⁵와 등가원리 재검토 (원문 대조 후)

### 9.1 철회하거나 해소된 지적
6π⁵ 사슬(§5, §7, §8.0.5–8.0.6, §9.4, §13.5)을 끝까지 따라가 보니, 아래 네 지적은 물리의 결함이 아니라 **본문에서 생략된 한 문장**이었다. 빠진 문장은 새 장 §MR에 보강했다.

| 지적 | 해소 |
|---|---|
| S¹ 평균 대 S² 평균 (이슈 56) | 회전축이 노즐 대각선에 고정되어 있다. 따라서 변하는 것은 고정축 둘레의 위상이고, 위상은 원(S¹) 위에 있다. 구(S²) 평균은 축 방향이 무작위일 때 묻는 다른 질문이다. |
| n = 3은 2D에서만 강제된다 (이슈 58) | 섹터는 회전 평면에 있다. 평면 밖 방향은 이미 노즐 축이 차지하고 있다. 입방체의 대각선 둘레 대칭은 C₃다. |
| 지수 n−1의 출처가 두 곳 (이슈 9) | 두 설명은 같은 뺄셈을 양쪽에서 본 것이다. 게이지 계수에서 빠지는 전역 모드가 곧 노즐을 통과하며 δ 하나를 치르는 모드다. 따라서 −1은 하나뿐이다. |
| 1/δ가 δ의 역할 제한을 위반한다 (이슈 57) | 1/δ는 성공 한 번당 평균 시도 횟수(기하분포의 평균)다. δ는 계속 생존 확률로만 쓰인다. |

### 9.2 실제로 수정한 것
- **6π⁵ 등급.** 등급을 "[F | LOCK-NU-N]"으로 명시했다. 선언된 대응(생존 → 비율)을 받아들이면 강제된다는 뜻이다. 잔차 −18.8 ppm은 다음 차수 보정으로 보고 [O]로 기록했다. 보정을 유도하면 그 부호와 크기를 비교 전에 먼저 명시하도록 규칙을 적었다.
- **§1.8.3 "ALL PASS … framework is wrong".** 이 검사를 "산술 일관성 검사"로 재표기했다. 허용치 2×10⁻⁴가 잔차보다 넓어서 데이터로는 실패할 수 없기 때문이다.
- **look-elsewhere 확률.** n·πᵏ 문법에서 이 정밀도로 우연히 맞을 확률은 약 4×10⁻⁴이다. 스크립트는 `repro/physics/experiments/LEE/lee_6pi5.py`에 있고, Lenz(1951)를 선행 기록으로 인용했다.

### 9.3 등가원리: 시뮬레이션 한계가 아니라 결합 규칙의 문제
- 1/r² 법칙은 `F = Qₜ·p₁(r)`에서 나온다. 이 식에 따르면 시험 물체의 가속도는 Qₜ/mₜ에 비례한다.
- 그러므로 등가원리가 성립하려면 물체의 흡수율(Q)이 질량에 비례해야 한다.
- 그런데 §13.5의 비율–질량 관계에서 m/ν는 양성자가 2π, 전자가 1로 입자마다 다르다.
- 따라서 갈림길이 생긴다. (a) 중력이 사건 수가 아니라 질량-에너지에 결합한다고 선언하고 유도하거나, (b) 약 10⁻⁴ 수준의 조성 의존 낙하를 받아들여야 하는데, (b)는 MICROSCOPE 실험이 배제한다.
- 이 갈림길은 §17에 명시했다. cap 영역 밖의 등가원리는 [O]로 두었다.
