# 연구 방향 — 워크스트림 M*: 계별 메틸화 리더 (식물용/곤충용) + 메틸화-체제 자동판별기

**선행:** §11/U3 — M층의 CpG-O/E 기질은 **척추동물 모양**이다(척추+식물은 메틸화, 초파리·선충·효모는
안 함). **목표:** 식물용·곤충용 M-리더를 실제 NCBI 데이터로 구축하고, 하나의 **자동판별기**로 통합한다.

---

## 1. 설계를 결정한 발견 (측정, 정립 생물학에 근거)

메틸화는 **맥락(CG/CHG/CHH)**만 다른 게 아니라 **건축양식(architecture)**이 다르며, 양식마다 **읽는 전략**이
달라야 한다. 틀린 방식으로 읽으면 **거짓 음성**이 나온다.

- **(V) 척추동물 — 전역 CG 도배.** 게놈 전체가 CG 메틸화 → CG 고갈이 게놈 전역 → **벌크 창** 어디서든
  읽힘. (사람 벌크 CpG O/E ≈ 0.13)
- **(P) 식물 — 전역 CG + CHG (+ CHH), RdDM.** CG **와** CHG 고갈이 게놈 전역 → 벌크로 읽히되 **비-CG
  맥락도** 읽어야 함. (식물 CG 0.52–0.77, CHG 0.68–0.94 고갈; CHH ≈1.1 — 희소 비대칭, 비고갈)
- **(I) 곤충 — 표적 유전자체(gene-body), 있을 때(벌목: 꿀벌·말벌) / 없음(파리목: 초파리·모기).**
  메틸화가 **유전자 일부**에만 → **벌크 고갈이 없음**(메틸화하는 꿀벌조차 벌크 CpG O/E ≈ 1.4!). 신호는
  **유전자 단위(per-gene)**에서만, 저-CpG(체메틸화) 유전자 클래스로 보임. (꿀벌 per-gene: 넓은 분포, 12%
  유전자 <0.6; 초파리: 좁은 ≈0.96, 0%)

**핵심 원리(진짜 업그레이드):** M층은 메틸화 **양식에 맞춰** 읽어야 한다. 단일 벌크-CpG 읽기(§9의 척추동물
기본값)는 표적 메틸화하는 꿀벌에 대해 **"기질 없음"이라 거짓 보고**한다. 자동판별기는 벌크 CG/CHG를 먼저
읽고, 전역 신호가 없으면 per-gene으로 **승급**해 — 척추·식물·표적곤충·비메틸화곤충을 모두 옳게 분류한다.

## 2. 구축물

### 식물 리더 (CG + CHG + CHH)
- 6종(애기장대·벼·옥수수·콩·토마토·이끼) 전부 CG **와** CHG 고갈 → 식물 서명. 기저식물 **이끼**까지 포함.
- 자동판별기가 6종 모두 `PLANT_global_CG_CHG_CHH`로 라우팅. 척추(CG만)·곤충(없음)과 구별.

### 곤충 리더 (2부)
- **(A) 벌크엔 전역 메틸화 없음** — 어떤 곤충도 벌크 CG 고갈 없음(메틸화하는 벌도 ≈1.4 vs 척추 0.13).
  곧 **양식 자체가 척추/식물과 다름**.
- **(B) per-gene이 표적 유전자체 메틸화를 드러냄** — 꿀벌(벌목)이 임계 통과(per-gene 분산 0.31, 저-CpG
  유전자 12%; Elango/Lyko 이봉 서명). 파리목(초파리·모기)은 좁은 ≈1, 메틸화 클래스 없음 → 기질 불활성.
- **정직한 경사 [O]:** 말벌·누에·딱정벌레는 이 표본 크기에선 임계 미만(약/희소 메틸화와 일치) → 해결엔 더
  큰 RefSeq mRNA 패널 또는 직접 WGBS 필요(명시된 [O], 침묵 아님).

### 자동판별기 (하나의 라우터, 모든 체제)
벌크 CG/CHG 먼저 → 전역 신호 없으면 per-gene 승급. 보편 M층: 읽기를 양식에 맞춤. (5/5 테스트 정답)

## 3. 서열 가독 vs 외부 데이터 (정직한 경계)

| 항목 | 서열로 | 외부 데이터 필요 |
|---|---|---|
| 메틸화 **양식** 판별(전역/표적/없음) | ○ (벌크+per-gene 고갈) | — |
| 식물 CG/CHG/CHH 기질 위치·맥락 | ○ | — |
| 곤충 표적 유전자체 클래스 존재 | ○ (per-gene) | — |
| 절대 메틸화 β (맥락·조직별) | × | 척추 WGBS / 식물 CX-report |
| 약신호 곤충(말벌/누에/딱정벌레) 판정 | △ | 더 큰 mRNA 패널 또는 종별 WGBS |

## 4. 미해결 질문 등록부 — 모두 [O], 닫는 데이터셋 명시

- 맥락별 절대 메틸화 β(식물 CG/CHG/CHH, 척추 CG) — 종·조직별 WGBS/CX-report.
- 약신호 곤충의 표적 메틸화 정량 — 큰 유전자 패널 또는 직접 WGBS.
- per-gene 신호와 실제 유전자체 메틸화의 일치도 — 종별 WGBS 대조.

## 5. 정직성 가드

- γ 읽기전용 불변; append-only(잠긴 파일 무수정). 자동판별 임계는 §11 측정에서 유도(자의적 아님).
- "거짓 음성 회피"가 요점: 벌크만 읽으면 꿀벌을 놓침 — 그래서 양식별 읽기. principle-demonstration이며
  임상 예측 아님. 절대 β·약신호 곤충은 [O]로 명시.

## 6. 한 문단 요약

§11이 "M층이 척추동물 모양"임을 보였고, 여기서 **식물용·곤충용 리더**를 실데이터로 만든다. 식물은 CG+CHG+CHH를
벌크로(이끼까지 6종 확증), 곤충은 — 벌크엔 전역 메틸화가 없으므로 — **per-gene으로 표적 유전자체 메틸화**를
읽는다(꿀벌 명확, 파리목 없음). 둘을 **자동판별기**가 통합한다: 벌크 먼저, 없으면 per-gene 승급. 깊은 원리는
메틸화 기질이 **맥락이 아니라 건축양식**이라는 것 — 양식대로 읽지 않으면 꿀벌처럼 거짓 음성이 난다. 16개 항목
중 14개 [F]/[L] 양성증거, 2개 [O]는 닫는 데이터셋 명시 — 침묵이 없다.
