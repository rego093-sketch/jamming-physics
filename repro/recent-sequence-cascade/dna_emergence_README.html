DNA Emergence bundle — overview

This directory carries two self-contained sub-packages, each with its own whitepaper, governance, reproducibility map, manifest, modules, and a repro/ spine:

  • animal/ — VP Recent-Sequence DNA Emergence (mammoth/elephant, Neanderthal/human).
  • plant/ — VP Plant Environment DNA Emergence (cold vs UV; material γ as a lineage property, not an environmental one).

Run / verify

For the animal package: cd animal/repro && python3 vp_gamma_engine.py (deterministic γ self-test), then python3 run_all.py (→ results/RESULTS.txt + figure). For the plant package: cd plant/repro && python3 vp_gamma_engine.py, then python3 run_all.py. Both verify their MANIFEST.sha256 byte-for-byte. SEED = 19, no fitted parameter.

Why DNA is neutral on the cascade's occurrence is covered in Module 22.
