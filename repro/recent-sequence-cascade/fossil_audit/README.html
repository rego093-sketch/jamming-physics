Fossil-count audit

Raw radiocarbon counts, computed directly from a published global database, with no imported causal model.

This component exists because a data claim must be audited the same way an interpretation is (see ../GOVERNANCE.md, Article 7). During development the record was first described from memory as "densely documented" — wrong — and the sparseness was then explained by importing an external model (taphonomic bias) — an asymmetric firewall violation. The correction was to fetch the primary database and count, and to hold every causal story ([O]) symmetrically.

What it shows (counts only)

Running fossil_counts.py over 179,689 real radiocarbon dates (p3k14c) and the 1,795 that are self-tagged as human remains:

  • [V] Early-Holocene human-remains counts are genuinely small in absolute terms — single dozens per millennium at 8,000–12,000 BP, versus hundreds at 2,000–5,000 BP. The original observation that ancient remains are sparse is correct.
  • [V] The count drops toward the present (fewest in 0–500 BP, peak at 2,000–3,000 BP). Under uniform dating plus more recent people plus better preservation, the most recent bin should be richest; it is not. This is the fingerprint of recent remains being under-dated (a known-recent skeleton is not ¹⁴C-dated).
  • [L] Correcting for that under-sampling would raise the recent counts and make the ancient/recent contrast larger — consistent with "ancient genuinely sparser."
  • [O] Whether the ancient sparseness reflects true scarcity or preservation/discovery loss is undecided: this database counts dated samples, not existing remains (DISCOVERED ≠ EXISTING).
  • [O] The cause of ancient sparseness — flood, low ancient population, or preservation — is not decided by counts. A small early-Holocene population predicts the same sparseness, so the counts do not discriminate. Cause belongs to the history channel.
  • [O] Strong sampling-rate claims (e.g. "0.01% vs 100% dated") need an existence denominator this database does not contain.

Why no causal model is imported

The discipline is symmetric. Just as the flood explanation is held [O], so is taphonomy, so is demography. The counts are the only [V] object; importing any one model to settle the meaning of the counts would re-commit the violation this component was built to correct. The counts feed the history channel; they do not adjudicate it.

Reproduce

pip install pyreadr --break-system-packages      # to read the R .rda file
python3 fossil_counts.py                          # prints tables, writes results/RESULTS.txt

Data provenance: p3k14c, a synthetic global database of archaeological radiocarbon dates — Bird, D., Miranda, L., Vander Linden, M. et al., Scientific Data 9, 27 (2022). Scrubbed/fuzzed release data/p3k14c_data.rda, from https://github.com/people3k/p3k14c .

Status

This is an open, ongoing strand (the "DNA-fossil research needs more work" note). What is settled: the counts ([V]) and their grading. What is not: an existence-calibrated sampling model, and any causal attribution — both deferred to the history channel and to further data.
