Module 43 — Carbon-budget closure: enough carbon for the oil

In plain terms. Is there actually enough carbon in a source rock to make a giant oil field? Run the numbers: a normal world-class kitchen (5% organic carbon, 50 m thick, 100,000 km²) generates roughly 700–1300 billion barrels — the same ballpark as a single giant province holds (100–900 billion). So “there isn't enough carbon for one-event charging” is simply wrong; there is. This shows sufficiency, not that it was one event — the same rock works for the mainstream too.
