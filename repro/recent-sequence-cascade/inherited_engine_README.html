Inherited engine bundle — overview

This bundle gathers the physics-bridge prototype code, results, and figures of the Atlantic-expansion (TGU-ATL-A) work into one place, so that every numerical claim is checkable by re-running it. It is inherited whole and frozen; the cascade audits it rather than taking it on faith.

Structure

The bundle carries a single verification runner (validate_all.py, which maps every claim to PASS/STOP), a claim→script→result ledger (LEDGER.md), a checksum manifest (SHA256SUMS.txt), and the deterministic engine scripts (engine/, NumPy/SciPy, seed-fixed). The engines are the void-suction + unjamming core the cascade inherits as its rupture mechanism.

Run / verify

From the bundle directory: python3 validate_all.py runs all claims to PASS/STOP; sha256sum -c SHA256SUMS.txt checks integrity. Both are also asserted automatically by the top-level repro/verify_all.py (engine 39/39, SHA 60/60). SEED = 19, no fitted parameter.
