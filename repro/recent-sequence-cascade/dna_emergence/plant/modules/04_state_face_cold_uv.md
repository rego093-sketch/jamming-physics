# Module 04 — The cold-vs-UV STATE face: the environment does not write the material (H3)

**Author:** Young Jae Lee · ORCID 0009-0002-7535-8245 · CC BY 4.0 · https://jamming-physics.org/
**Tier:** emergence (the user's hypothesis) · **Inherits:** Modules 01–03 · **Status:** measured on real cold/UV genes · **Grade:** [V]

**One line.** A cold plant and a UV plant differ in *which switch is deployed* and *how strongly* — not in the readable material, which is a lineage property.

---

This is the user's question, tested directly on **real cold- and UV-response genes** (`repro/state_face_cold_uv.py`). Three reads.

**(1) Inventory — the cold switch and the UV switch are different loci.** The cold-acclimation master switch is **CBF/DREB1** (Arabidopsis CBF1/2/3, γ ≈ 1.368–1.425); the UV-protection switch is **CHS** (chalcone synthase, γ ≈ 1.437) with **UVR8** as the UV-B sensor (γ ≈ 1.352). These are **different genes**: the environment deploys a *different switch* (cold → CBF, UV → CHS/UVR8), not a different material.

**(2) The environment does not set the material; the lineage does.** Read CHS — the UV switch — across six contrasting habitats:

| species | habitat | γ |
|---|---|---|
| barley | **COLD** cereal (grass) | **1.596** |
| maize | **WARM** C4 (grass) | **1.645** |
| Arabidopsis | temperate dicot | 1.437 |
| grape | **HIGH-UV** dicot | 1.450 |
| snapdragon | temperate dicot | 1.442 |
| petunia | temperate dicot | 1.316 |

A **cold** grass (barley) and a **warm** grass (maize) **both read high** *because both are grasses*; a **high-UV** dicot (grape) reads with the other dicots. **The cold / warm / UV environment does not sort CHS γ — the lineage does.** So the environment does **not** write the readable material.

**(3) Within one lineage, the cold and UV switch genes share a material scale.** Within Arabidopsis the cold-switch and UV-switch genes span γ ≈ 1.352–1.437 — a single material scale; the cold-vs-UV difference is *which switch is deployed* plus localized coding, not a material shift.

**Verdict.** *"Cold-environment and UV-environment plants have similar genes, even though they look different"* is **TRUE in the precise sense that the readable material (γ) is set by the LINEAGE, not by the environment.** The environment sets **which switch is on** (inventory) and **how much** (dwell/expression); "they look different" lives in STATE.

**Honest caveat (refused over-claim).** γ is a composition measure, so cross-lineage CHS γ varies (grass vs dicot). We do **not** claim "any cold gene ≈ any UV gene." The defensible claim is directional: **the environment does not rewrite the material.**

**Grade [V]:** cold and UV are different loci; γ is a lineage property; the environment writes to STATE/inventory/dwell, not the material. Any "past cold greenhouse" stays **[O]**.
