# Module 05 — γ is a composition measure (which is *why* it is a lineage property)

**Author:** Young Jae Lee · ORCID 0009-0002-7535-8245 · CC BY 4.0 · https://jamming-physics.org/
**Tier:** instrument honesty · **Inherits:** Modules 02, 04 · **Status:** measured · **Grade:** [V]

**One line.** γ rises with GC content; a lineage's genome GC sets its γ scale — and that is the mechanism behind "the environment does not write the material."

---

Why is γ a *lineage* property and not an environment property? Because **γ = −mean(NN ΔG) is a base-composition measure**: GC-rich windows stack harder and read higher γ. We show this directly (`repro/length_composition.py`):

- plastid genes pooled across all six taxa (n = 372): **r(γ, GC) = 0.979**;
- CHS across six species: **r(γ, GC) = 0.998** — grass CHS GC ≈ 0.66–0.70 → high γ; petunia GC ≈ 0.42 → low γ.

A lineage's genome GC content sets its γ scale, and **GC architecture is heritable lineage structure, not something the cold or UV environment rewrites.** This is *exactly why* the material is a lineage/kind signature the environment cannot write to — the composition link is the **mechanism**, not a flaw.

It also **bounds the reading**: compare γ **within** a lineage, or control GC, before reading a difference as material. This is why "any cold gene = any UV gene" is refused (§Module 04) — cross-lineage CHS γ varies because genome GC varies.

**Grade [V]:** γ↔GC composition link measured; it explains and bounds the H1′/H3 readings.
