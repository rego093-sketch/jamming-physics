## A. 왜 목표(모두 커버)에 도달하지 못했는가 — 근본 원인

핵심은 한 문장이다: **이 패키지의 설계 범위(scope)가 처음부터 "인간(포유류) 한 종의 광물/산-염기/전해질 항상성"이었고,
사용자가 새로 제기한 목표("동물계 전체 구분 + 모든 이온 질환")는 그보다 훨씬 넓은 별개의 목표이기 때문이다.**

1. **헌장 범위의 한계.** `CHARTER.md`는 이 권을 "the third homeostasis **axis**"로 정의한다 — 즉 *인간 생리의 한 축*이다.
   종간 비교(comparative physiology)는 헌장에 들어 있지 않았으므로, 아무리 완성도를 높여도 자동으로 충족될 수 없었다.
2. **v0.4.0의 실제 목표는 달랐다.** v0.4.0의 목표는 "프런티어 4가설 정량화 + DOI 발행 준비"였고 그것은 100% 달성했다.
   "모두 커버"는 그 시점의 목표가 아니었다 — 목표가 사후에 확장된 것이다(이것이 정상적인 연구 진행이다).
3. **γ 측정의 종 제약.** 이 권의 모든 γ는 **인간 프로모터**(RUNX2·CASR·VDR·GCM2·SIX2)에서만 측정됐다.
   다른 종(어류·무척추동물)의 마스터 유전자 γ가 없으므로, 종간 정량 모델은 데이터 부재로 불가능했다.
4. **질병 커버리지의 설계 의도.** 병리 모듈은 "흔한·폴리제닉·후천성·노화" 대표 질환 7종을 6개 실패모드로 닫고,
   **희귀/단일유전자형은 cited parameter로 진입**시키는 구조였다(by design). 따라서 마그네슘·CKD-MBD·종양성 고칼슘혈증 등
   일부 중요 질환은 "아직 명시 안 됨"이지 "틀려서 빠진 것"이 아니다.

> 결론: 미달의 원인은 오류가 아니라 **scope mismatch**다. 단일 종 임상 항상성 모델 ≠ 비교 이온조절 생물학.
> "모두 커버"는 본질적으로 **다(多)-증분 프로그램**이며, 한 세션/한 버전으로 닫히지 않는다. 그래서 티어로 분할한다.

## C. 티어 로드맵 (digestive 패키지의 Group A/B/C 패턴 준용)

- **Tier-1 (1차 = v0.5.0, 완료):** **G1**. 가장 큰 갭. 기존 OU 법칙 재사용 → 종간 구분을 가산적으로 추가.
- **Tier-2 (2차 = 이번 v0.6.0, 완료):** **G2·G3·G4**. 모두 *기존 6개 실패모드*(setpoint drift / reservoir / threshold / loop-gain)의
  재사용으로 닫음. 새 프리미티브 불필요. 인간 질병 커버리지를 "대표 7종"에서 "주요 이온 질환 거의 전부"로 확장 (D2절 참조).
- **Tier-3 (3차 = v0.7.0, 완료):** **G5·G6**. 새 프리미티브(채널 게이팅 동역학) + 외부 데이터(종별 프로모터 γ 실측).
  G5는 GHK 정전장 플럭스+게이팅을 추가하고 그 막 플럭스 기울기 k=−dJ/dC가 OU 루프게인과 동일함을 보였다 [F]/[V].
  G6는 ATP1A1 프로모터 γ를 6종 실측했으나 **honest negative** — γ는 루프게인 k가 아니라 프로모터 GC를 추종(Spearman 1.0)하므로
  비교 절대 k는 [O]로 남되 이제 그 GC 교란을 명시된 사유로 갖는다. G1의 절대화는 "잘못된 측정 도구" 진단으로 닫혔다 (D3절 참조).

## D1. 1차 보완 — v0.5.0이 실제로 닫은 것 (G1)

**새 모듈 `repro/_engine/comparative_ionoregulation.py`** — "어떤 동물이 이온을 정밀 유지하고 어떤 동물이 환경에 순응하는가"를
**같은 R19 기질** 위에서, **이 권 자체의 폐루프 법칙**(`vp_loops.ou_setpoint`의 step error = load/k)을 재사용해 구분.
단일 손잡이는 loop gain k(= 외부 염도 부하에 맞서 내부 환경을 방어하는 정도):

| osmotic 전략 | 분류군(예시) | k | 환경 추종률(=1/k) |
|---|---|---|---|
| osmoconformer | 대부분 해양 무척추동물 | 1.0 | 100% (환경 1:1 추종) |
| urea-retaining elasmobranch | 상어·가오리(요소+TMAO 순응, 무기이온 조절) | 2.0 | 50% |
| hyperosmotic regulator | 담수 경골어·양서류 | 3.0 | 33% |
| hypoosmotic regulator | 해수 경골어 | 3.0 | 33% |
| terrestrial regulator | 포유류(인간; 이 권의 baseline) | 4.0 | 25% (최정밀, 75% 방어) |

**재현된 결과(결정론, 2×sha 동일):** 순응자는 염도 부하에서 내부가 끌려가고(offset 1.00), 육상 조절자는 버틴다(0.25) —
비(比) 4.0× == 게인비 k_reg/k_conf(4.0), 즉 이 권 자신의 load/k 법칙. 환경 스윕에서 순응자는 환경 변동의 100%를 추종,
조절자는 25%만 추종 → **조절자가 정밀 이온 사용자**. 내부 이탈은 다섯 전략에 걸쳐 loop gain에 대해 단조.
**정직 등급:** 분류군↔전략 배정 = 인용 **[L]**(Schmidt-Nielsen / Evans / Ballantyne); 순서·분리 = **[V]**;
절대 k·염도 견딤범위(euryhaline vs stenohaline) = **[O]**; 종별 마스터 유전자 γ 미측정 = **[O]/[H]**.

**배선:** `run_all.py` 섹션 **[10]** 추가(GATES→[11]); `literature_anchors.py`에 **A-OSMO** 추가;
정본 docs **§10 "Comparative ionoregulation"** 페이지 추가(answer-first 57단어·JSON-LD×2·claim-strip, C4 충족).
**가산적** — 연구 게이트(γ-창발+스트레스 배터리)는 이 모듈을 import하지 않으므로 **연구 sha `35d31461…` 불변**, all_green.

  loss-of-function 수송체는 *막에서의 loop-gain-drop*(TRPV5/6 신장 Ca 소모; ENaC/SCNN1A→PHA1; H⁺-ATPase/ATP6V→원위 RTA)임을 보임 [V].
- 등급: GHK+게이팅 [F]; k=−dJ/dC=OU 게인 [V]; 절대 단일채널 컨덕턴스/채널 밀도 [O](전기생리 캘리브레이션 잔차).

### ✅ G6 종별 γ 실측 — v0.7.0 완료 (HONEST NEGATIVE, §13)
- `repro/_engine/comparative_gamma.py` + `inherited/comparative_promoters.cache.json`. osmoregulatory 마스터 유전자 **ATP1A1**(Na⁺,K⁺-ATPase α-1)
  프로모터 γ를 6종(굴·은상어·홍어·제브라피시·제노푸스·인간) 실측 — 동일 NN-stacking 파이프라인, 인간 앵커 재현, 오프라인 재현 [V].
- **결과 = honest negative:** γ는 루프게인 k에 대해 비단조(Spearman 0.65; k=3.0 제노푸스 γ가 k=4.0 인간 γ 초과)이며 대신 프로모터 **GC를 거의 완벽 추종**(Spearman 1.0).
  파이프라인은 건전(독립 연골어류 2종 γ±0.0003). → **종내 γ-사다리는 단일유전자 종간 비교로 전이되지 않는다(GC 교란).**
- 결론: 비교 절대 k는 [O]로 유지하되 이제 **GC 교란을 명시된 사유**로 가짐(bare placeholder 아님). 진짜 grounding은 GC-통제 또는 계통내 비교가 필요 — 다음 도구로 명시.

## F. 최종 목표 대비 현재 진행률 (정직)

"세 축 모두 커버"는 **다-증분 프로그램**이었고 v0.7.0에서 **완결**된다:
- **(1) 동물 구분:** v0.4.0 ❌ → v0.5.0 ✅(방향 [V]) → **v0.7.0: 절대화 시도 = honest negative**(G6; 종별 γ는 k가 아닌 GC 추종, 절대 k는 명시된 사유로 [O]).
- **(2) 정밀 유지 기제:** 시스템 제어 골격 ✅ → **v0.7.0: 분자 수송 동역학 ✅**(G5; GHK+게이팅, k=−dJ/dC=루프게인).
- **(3) 이온불균형 질병:** 대표 7종 ✅ → **주요 거의 전부 ✅**(v0.6.0 Tier-2: 마그네슘·CKD-MBD·종양성 고칼슘혈증).

> v0.5.0이 가장 큰 갭(동물 구분)을, v0.6.0이 질병 커버리지를, **v0.7.0이 분자 동역학(G5)과 종별 γ(G6, honest negative)** 를 닫아 "모두 커버"를 완결한다.
> 모든 증분은 가산적이고 연구 게이트(`35d31461…`)를 보존하며 — Tier-3에서 남는 유일한 [O]는 G5의 절대 전기생리 캘리브레이션이다.
