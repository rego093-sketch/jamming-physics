## 1. One-command reproduction

Requirements: Python 3 with **numpy** only. No network access is needed; the run
is fully offline and deterministic.

```
python repro/run_all.py
```

This emerges the organs from measured DNA, builds the circulatory/renal/hepatic
physiology, runs the full stress + oncology battery, writes `reports/`, and prints
the research gate. On success the writing-lock is released and the run prints a
byte-identical result digest.

**Expected result digest (SHA-256):**

```
short : d8610156dcddf17e
full  : d8610156dcddf17e57bea331a5c4972721234febf3b2e543bd5fd988be901c29
```

Two independent executions yield the same digest (determinism contract below).
All 23 discriminant targets must report PASS.

Other entry points:

```
python repro/_engine/vp_cir_engine.py   # just the organ-emergence JSON (+ sha256)
python repro/_verify/gates.py           # research gate + writing-lock status
```

## 2. Determinism contract (VP-SPEC C1)

BLAS is pinned to a single thread before numpy is imported; a fixed seed is used;
values are rounded before hashing; JSON keys are sorted. Every number that appears
anywhere in the volume is regenerated by the engine — there are no hand-entered
values. Source is standard-library + numpy only.

## 4. How the science is graded

Every quantitative claim carries one grade, kept visible on every page:

- **[F] forced** — the relation is structurally derived (no free parameter).
- **[V] simulation-verified** — the engine reproduces the cited operating point.
- **[L] literature-anchored** — an absolute input is a cited measurement.
- **[O] open** — a value is not yet reproducible; its obstacle is named, never fitted.
- **[H] hypothesis** — a stated, falsifiable prediction.

Absolute organ mass and absolute cancer incidence are logged `[O]` with their
obstacles named (see `IRREPRODUCIBILITY_LEDGER.md`), never fitted to look settled.
