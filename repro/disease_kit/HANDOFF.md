## 0. 한 문장 — what this is

A self-contained kit that pulls **real NCBI DNA**, **emerges** a disease's promoter switch with
the R19 / γ engine, reads the disease as a **perturbation** of that switch, and reasons about
**treatment directions** via two pathways (A: switch adjustment, B: VP-chemistry feasibility) —
under a strict firewall (direction `[F]`, magnitude `[O]`) and a suspension rule
("DNA 없으면 보류"). It **complements** `disease_wp` (concept DOI 10.5281/zenodo.20763842 — the reproducible burden-ordering + standard-of-care context layer); this kit adds the DNA-emergence → perturbation → treatment-direction layer. See `README.md` for
the full pivot.

## 2. 어떻게 작동하나 — the chain (so you can extend it)

```
fetch/ncbi_gene_promoter.py     gene symbol -> NCBI coords -> promoter FASTA -> γ  (caches; offline-replayable)
        │
pipeline/emerge_disease.py      γ -> R19 switch (|h_sp|, barrier) ; (role × mechanism) -> perturbation DIRECTION [F]
        │                       picks the PRIMARY switch = deepest barrier among direction-bearing genes
        ├── pipeline/treatment_switch.py   PATHWAY A: corrective levers (oppose pathology), ranked by approval ;
        │                                  emerge disease/treated/healthy dwell (ordering [F], magnitude [O])
        ├── pipeline/treatment_chem.py     PATHWAY B: VP-chem feasibility (ΔG, Sabatier) ; flags [O] missing numbers
        │
pipeline/honesty_gate.py        GATE 1 forbidden-claim scan (no derived dose/Kd/IC50/cure%/clinical mV ;
        │                       firewall string required ; [O] disclosure required) — fail-closed
        │                       GATE 2 falsifier register (≥1 measurable falsifier per disease)
        ▼
diseases/<slug>/analysis.json   the shipped artifact (carries determinism_sha)
repro/run_all.py                runs all of the above + freezes repro/expected_sha256.json
```

**The firewall is the whole point:** γ reads switch STRUCTURE only; DIRECTION is forced + cited;
MAGNITUDE / affinity / dose / efficacy / cure are always `[O]`; nothing is advice for any
individual. If you cross it, GATE 1 fails the build.

## 3. 새 질병 추가법 — to add a disease (the main loop)

1. **Edit `diseases/_registry.json`.** Add one entry under `"diseases"` keyed by slug. Required
   fields (copy an existing one — `achondroplasia` is the fullest template):
   - `disease`, `omim`, `organism` (default `"Homo sapiens"`), `emergent_axis` (the phenotype axis)
   - `causal_genes`: list of `{symbol, role, mechanism, note, src}` where
     - `role` ∈ {`brake`, `accelerator`, `channel`, `enzyme`, `master_TF`, `morphogen`, `structural`}
     - `mechanism` ∈ {`GOF`, `LOF`}
   - `therapeutic_axes`: candidate levers `{lever, target_gene, agent_class, status, src}`
     (`lever` ∈ reduce/potentiate/correct/oppose/restore/replace; `status` ∈ approved/investigational/none)
   - `chem_candidates` (optional, enables pathway B): `{name, modality, dH_kcal?, dS_cal_per_K?, dG_bind_kcal?, rationale, status, src}`
   - `falsifiers`: ≥1 named, **measurable** statement that would overturn the read.
2. **Make sure the genes' promoters are cached.** With network:
   `python3 fetch/ncbi_gene_promoter.py SYMBOL` for each new gene (it appends to the cache).
   Without network you can only use already-cached genes.
3. **Run it:** `python3 pipeline/analyze_disease.py <slug> --offline` then
   `python3 repro/run_all.py` (the harness auto-appends the new disease's hash on first sight,
   then enforces drift 0 thereafter).
4. **If the disease has no single-gene promoter switch → SUSPEND it.** Set
   `"status": "suspended"` and `"suspended_reason": "..."`. Do not force a read. (See
   `down_syndrome`.) Add the suspension to `docs/IRREPRODUCIBILITY_LEDGER.md` §C.

**Suspension test (apply honestly):** is the cause a single gene whose promoter switch you can
read? If it's a whole-chromosome/large-CNV/polygenic/epigenetic cause → SUSPEND. "없으니 못한다."

## 5. 불변식 — invariants you must not break

- **Self-contained (C1):** no external absolute paths; engine vendored; NCBI cache bundled.
  `repro/run_all.py` must run offline.
- **Determinism:** every artifact carries `determinism_sha`; `repro/run_all.py` must stay drift 0.
- **Three independent freezes (modules+site since v0.28.0):** the 78 per-disease hashes
  (`repro/expected_sha256.json`, stage S4), the **6** module hashes (`repro/expected_modules_sha256.json`,
  stage S5 — 3 inherited analgesic modules + 3 native: II-A direction-recovery scoreboard, III-A2 repurposing
  scanner, III-A open-directions cards), and the **4** site-file hashes (`repro/expected_site_sha256.json`,
  the IV-A canonical site) are **separate**. The modules are **read-only** over the frozen `analysis.json`
  artifacts and must **never** edit `honesty_gate.py` or any `analysis.json` — that is what keeps the 78
  disease hashes drift 0 while the module + site outputs evolve. Every new native module follows the template
  (`pipeline/direction_recovery.py`): a build-failing self-test with teeth, a frozen output in
  `repro/modules/expected/`, addition to the M5v2 `claim_scanner_v2` NEW_MODULES scope, and read-only access
  to the frozen artifacts.
- **`axis_family` taxonomy is fail-closed (since v0.28.0):** `pipeline/repurposing_scanner.py` carries a
  curated `AXIS_FAMILY` map (molecular CORRECTIVE-AXIS level — what is pushed + how, NOT the organ); the gate
  **FAILS CLOSED** if any resolved disease is unclassified, so every future disease-add MUST be honestly
  assigned a molecular-corrective-axis family (an existing one, or a new one explained in the changelog). The
  scanner asserts only the (axis_family × direction × lever_class) signature + a falsifier per hypothesis;
  magnitude / efficacy / potency stay [O]. After any disease add, the scanner + cards MUST be re-run.
- **Canonical site is deterministic & firewalled (since v0.28.0):** `pipeline/build_site.py` reads only frozen
  JSON + metadata parsed from VERSION (NO clock read), so rebuilds are byte-identical; the patient-facing
  disclaimer banner MUST be the FIRST `<body>` element of `index.html`; a NUMERIC-MAGNITUDE pattern gate (not a
  keyword ban) keeps any asserted dose/efficacy/rate off the page; staging `robots.txt` MUST block all indexing
  (`Disallow: /`) with the production allow-list commented for a one-line cutover; `llms.txt` stays under 5 KB.
- **Firewall everywhere:** structure read `[V]`, direction forced+cited `[F]`, magnitude/dose/
  efficacy `[O]`; never a treatment recommendation for an individual.
