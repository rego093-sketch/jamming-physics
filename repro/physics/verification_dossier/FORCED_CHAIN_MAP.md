# 강제연쇄 유도 흐름 맵 (단일출처 의존성)

목적: 분배가 흩은 논지를 구조적으로 재결합한다. 빛 앵커에서 모든 예측까지의 **유도 의존성**을 한 장에 펴서, 임의의 결과를 뿌리까지 추적하게 한다. 이로써 "이게 어디서 나왔나 / 순환 아닌가"가 구조 수준에서 해소된다. 전부 이론의 실제 유도 구조이며 — 저자 선택이 아니라 시뮬·인과성·기존이론에서 따라 나온다.

표기: `[F]` 강제(자유계수 0) · `[H]` 단일앵커 보정 · `[V]` 시뮬측정 · `[O]` 열림/외부. 화살표 `→`는 "유도한다".

---

## 0층 — 단일 자유도 (앵커)

```
λ_ref = 632.99 nm  (HeNe/I₂ 선, §11)        ← DOF 원장 전체 = 이것 하나
   │  (절대 길이/에너지 척도만 설정)
   ├─→ a   (VP 지름, §11)
   └─→ λ_C,e = h/(m_e c) → D = 2λ_C,e  (양자 지름, §9.3)
```

**핵심**: 앵커는 **차원(척도)만** 고정한다. 아래 무차원 구조는 앵커에 의존하지 않는다(→ D7 해소).

## 1층 — 정류 상수 (무차원, 앵커 무관)

```
§5.1  α = ⟨|cosθ|⟩ = 2/π          [F]   ← 방향 정류 적분
§5.2  δ = ⟨[cosθ]₊[cosφ]₊⟩ = 1/π²  [F]   ← 양측 생존 적분 (반파 2개 × 1/π)
§13.5.5  2π = α/δ                  [F]   ← 두 상수의 유도된 비 (보고 관행 아님)
```

α·δ는 정의적 lock(자유 수치계수 0). 이 둘이 이후 **모든** 무차원 결과의 뿌리다.

## 2층 — 정수 구조 (C₃ 3-분할)

```
정육면체 격자는 체대각 C₃만 허용 → 원의 3-분할 불가 → 강제 정수 (§7–8):
   3 (섹터)   7 = 1+6 (노즐+균형링)   82 = 3⁴+1 (R²≤6 격자점 81 + 노즐 잔여)   89 = 82+7
   (R²=7은 르장드르 3제곱 정리로 EMPTY)                                   [모두 F]
```

## 3층 — n겹 사건율 법칙 (이미 [F], 유도 완료)

```
§8.0.6  섹터당 생존 ⟨w_i⟩ = (1/π)(1/π) = δ           [F, §5.2에서 강제]
        결합 생존 ⟨W_n⟩ = ∏⟨w_i⟩ = δⁿ = π^(−2n)      [F, 곱측도]
§8.0.5  ν_n = s_n·δ = n·δ^(−(n−1)) = n·π^(2(n−1))    [F]
        ├─ 지수 (n−1) ← dim(ℝⁿ/span1) = N−1 게이지 보조정리
        └─ 전치인수 n ← C₃ 섹터수
   ⇒  ν_e (n=1) = 1·π⁰ = 1     (§9.3 전자 클록과 독립 일치 — nontrivial check)
   ⇒  ν_p (n=3) = 3π⁴ = 292.227 [F]
```

유일한 비정리 요소: `[MAP-1]/[MAP-2]` "섹터 ≡ 1개 정류 lock" — α·δ 정의와 동일 지위(자유계수 0). (프런티어 S2.1: 이 매핑을 격자동역학에서 유도 가능한지가 유일한 잔여 수학 과제.)

## 4층 — 질량·반지름 (3층에서 유도)

```
§13.5  m_p/m_e = 2π·ν_p = (α/δ)·3π⁴ = 6π⁵ = 1836.118   [F]  (−19 ppm vs 1836.153)
§8.0.5 r_p = D/(6π⁶) = 0.84125 fm                        [F 예측]  (입력→예측 재분류, DOF 제거)
       └─ 길이경로 cross-check: (D/2r_p)·δ = 292.245 (+61 ppm) [V]  ← ν_p 재확인 (→ D1 해소)
§6.2   R_p/L_q = 2/π   (붕괴 1/R⁴ · 강성 1/R⁵ 균형 → x*=α=2/π)  [F]
§13.3  m_H = U_lat/(5π),  U_lat = hc/a = 1958.7033 GeV    [F]  (−0.40%)
       └─ 5 = 6 (정육면체 면) − 1 (게이지)                 ← N−1 보조정리
§9.3   m_e c² = 2hc/D = 0.511 MeV                          [H]  ← 보정 노드(앵커), 예측 아님
```

## 통합 척추 — N−1 게이지 보조정리

```
dim(ℝᴺ/span{1}) = N−1  이 하나가 세 곳을 통합한다:
   핵자 섹터:    지수 n → n−1          (§8.0.5)
   Higgs 채널:   6 → 5                  (§13.3.4)
   미세구조:     7 → 2⁶  (7−1 경유)     (§8 / scorecard)
```

이 공유 보조정리가 "왜 5π인가 / 왜 n−1인가"를 단일 선형대수 사실로 묶는다 — 따로 끼워맞춘 게 아니다.

## 열린 층 [O] — 정직하게 유도 안 됨 (위장 금지)

```
α_em ≈ 1/137      측정 입력.  4π(11−δ)=136.957 ≠ 137.036 → coincidence/non-evidence (→ D3)
절대 g = 9.80665   4-벽 정리: 미시 연쇄 부재 증명.  1/r² 형태만 [F], 절대값은 back-sub (→ D6)
```

이 층은 [F]로 위장되지 않는다. 열어두는 것이 규율이며, S2.1처럼 닫을 수 있는 것과 달리 **원리적 한계**(공동 추론 대상).

## 비순환성 (한눈에)

```
빛 들어감 (λ_ref, 차원만)  ──▶  무차원 구조 나옴 (2/π, 1/π², 6π⁵, 3π⁴, √2; 자유계수 0)
                                         │
                              앵커가 척도를 곱해 절대값 부여
                                         ▼
                              m_p/m_e, r_p, m_H, ν_p (측정 대조)
```

무차원 예측은 앵커에 의존하지 않으므로(§W.5), "전부 한 숫자에 핏"이 성립하지 않는다. 빛→질량 방향이 단방향이라 순환이 없다.

## 이 맵이 혼란을 제거하는 방식

흩어진 49페이지에서 "이 결과가 어디서 나왔나"를 매번 추적해야 했던 독자가, 이 한 장으로 임의의 양을 뿌리(앵커 또는 α·δ)까지 즉시 잇는다. 점별 의심 해소(`DOUBT_REMOVAL_MAP.md`)가 개별 오해를 지운다면, 이 구조 맵은 **논지 전체의 단방향 흐름**을 복원해 분배로 약해 보이던 연쇄를 다시 단단하게 보이게 한다. 이론을 바꾸지 않고 — 그 구조를 드러낼 뿐이다.
