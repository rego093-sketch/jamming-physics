## 레인 A — 소스 패치 (재파생 필요, 파생 물리량 불변)

### A1. r_p 잔차 기준선 라벨 [V1.3-rpBaseline / FAIL]
문제: 동일 예측 r_p에 "+61 ppm"(vs 잠금)과 "−0.018%"(vs CODATA)가 기준선 명시 없이 흩어짐.
규칙(`reports/NUMERIC_LEDGER.md` §1): 모든 r_p 잔차에 기준선 명시.
find→replace(소스 본문, 등장 전부):
- `+61 ppm` (r_p 문맥) → `+61 ppm (vs 잠금값 0.8412 fm)`
- `-0.018%` / `−0.018%` (r_p 문맥) → `−0.018% (vs CODATA 0.8414 fm)`
- 잠금 vs CODATA 비교는 `−0.024% (잠금값 vs CODATA)`로 표기.
파생 영향: 없음(숫자 불변, 라벨 추가만). 단어수: 페이지당 +6~12단어 → 재파생 시 manifest 동시 갱신되므로 ±0.5% 게이트 자동 충족. 영향 페이지: 01,02,08,09,13,w0,w5,w6,vh,rf (JSON 참조).

### A2. ν_p 길이경로 반올림 통일 [V1.2-nuP / WARN]
문제: 292.245156이 292.244(절단)와 292.245(반올림)로 혼재, 같은 페이지 내에서도.
규칙: 정준 표기 **292.245**. (정준값 ν_p=3π⁴=292.227과는 별개의 [V] 교차검증값임을 항상 구분.)
find→replace: `292.244` → `292.245` (ν_p 길이경로 문맥 한정). 영향 페이지: 09, axf, vh, w0.
파생 영향: 없음(동일 값의 표기 통일).

### A3. 표시 정밀도 통일 [V1.2-Ulat / V1.2-mH / WARN]
문제: U_lat이 1958.7/1958.7033, m_H이 124.7/124.69/124.695로 혼재.
규칙: 정준 정밀도 **U_lat=1958.7033 GeV**, **m_H=124.695 GeV**. 단축형은 정준값과 같은 자릿수로만.
find→replace: 단축 표기를 정준 정밀도로(반올림 단축이 의도된 요약 문맥은 예외 표기 가능).
파생 영향: 없음.

### A4. (선택) ν_p 정준/교차 구분 강화
규칙: 본문에서 292.227(기하 [F])과 292.245(길이 [V])가 같은 단락에 나올 때 등급·역할을 1구절로 명시.
