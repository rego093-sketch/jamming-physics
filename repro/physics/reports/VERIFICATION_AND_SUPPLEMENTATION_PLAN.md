## 0. 범위와 불변 제약 (구조 유지의 의미)

### 0.1 무엇을 하고, 무엇을 하지 않는가
- **한다**: 내부 정합성 검증 — 수치 일관성, 강제연쇄(논지)의 무결성, 가독성·항행성, 게이트 통과. 그리고 그 위의 보완.
- **하지 않는다**: 물리 이론 자체의 옳고 그름 판정. 이는 명시적으로 후순위이며, 본 계획은 "분배로 내부가 깨지지 않았는가"만 다룬다. 외부 타당성 평가는 별도 트랙으로 분리한다.

### 0.2 불변 제약 — 이 백서의 자체 통치(governance)를 그대로 따른다
재구조화는 다음을 깨지 않아야 하며, 본 계획의 모든 작업도 이를 침범하지 않는다.

1. **src LOCK**: 봉인된 원본 sha(`305a5a24…`)는 불변. 검증은 감사·리포트만 하고 봉인 콘텐츠를 직접 고치지 않는다.
2. **tools LOCK / lane rules**: 도구류와 차선(lane) 규칙 불변. 세션은 자기 차선 밖 파일을 수정하지 않는다.
3. **LOCK → Derive → Gate 규율**: 모든 산출은 잠금 입력에서 파생되고 게이트로 봉인된다.
4. **No-Tuning 불변식**: 잔차(residual)를 줄이기 위해 [F](강제) 계수를 이동하지 않는다. (예: `5π`를 `4.98π`로 바꿔 Higgs 잔차를 닫는 행위 금지.) 버전이력(vh)의 원칙 — "잔차를 닫으려고 옮긴 [F] 계수는 없다" — 을 그대로 유지한다.
5. **구조 보존**: 49장 + 부록 + 허브 + 수식 SVG 레이아웃 유지. 단일 문서로 회귀하지 않는다. 보완은 **기존 슬롯 내 추가**(새 하위섹션·새 게이트·새 메타 필드)로만 한다.
6. **DOF 원장 = 1**: 자유 입력은 `λ_ref = 632.99 nm` 하나. 어떤 보완도 이 자유도를 늘리지 않는다.
7. **등급 체계 존중**: [F] 강제 / [H] 단일 앵커 하 보정 / [V] 시뮬 측정 / [O] 미결·외부입력. 격상은 등급 사다리를 따라서만 한다.

### 0.3 수정의 두 경로 (검증에서 결함이 나왔을 때)
검증이 불일치를 찾아도 임의로 숫자를 고치지 않는다. 두 경로로만 처리한다.
- **표시 전용(display-only)**: 반올림 절단, 잔차 기준선 라벨 누락처럼 **파생에 영향이 없는 표기 결함** → 표시 교정으로 처리(봉인된 파생 불변).
- **버전 필요(versioning-required)**: 파생 결과에 영향을 주는 실제 불일치 → 새 `lock_id` + 전면 재파생 + 게이트 재통과 제안서로만 처리. 즉석 패치 금지.

## 1. Phase 0 — 1차 정찰 결과 (이 계획의 실측 근거)

### 1.1 강제 수치 재계산 — 대부분 깨끗하게 검증됨
닫힌형에서 직접 재계산한 값이 본문값·잔차와 일치한다(상세표는 부록 A).

| δ | 1/π² | 0.1013212 | — | — | PASS |

즉 "분배로 강제연쇄의 핵심 수치가 통째로 깨졌다"는 일은 **없다**. 골격은 건강하다. 문제는 **잔차 표기와 교차참조 층**에서 발생했다.

### 1.2 발견 A — 잔차 기준선 모호성 (SSOT 라벨링 결함)
양성자 반지름 `r_p` 예측에 **서로 다른 기준선의 잔차가 동시에** 붙어 있고, 페이지마다 기준선을 명시하지 않는다.
- `D/(6π⁶)` vs 잠금값(0.8412 fm) = **+61.20 ppm** → 9개 페이지에 "+61 ppm"으로 등장.
- `D/(6π⁶)`(0.841251 fm) vs CODATA 전하반지름(0.8414 fm) = **−0.0177% ≈ −0.018%** → 3개 페이지에 "−0.018%"로 등장.
두 값 모두 수치적으로는 옳다. 그러나 **동일한 예측량**에 대해 한 페이지는 "+61 ppm", 다른 페이지는 "−0.018%"라고만 적어, 독자가 두 페이지를 오가면 화해시킬 수 없다. 분배가 드러낸 전형적 SSOT 결함. (참고: 과거 "+57 ppm"으로 흩어졌던 표기는 현재 0건 — 일부는 이미 정리됨. 그래서 **나머지 표준화가 더 시급**하다.)

### 1.3 발견 B — 반올림 불일치
`ν_p` 길이경로 교차검증값의 참값은 292.245156이다. 그런데 본문에는 **292.244와 292.245가 혼재**하며, 같은 페이지 안에서도 두 표기가 섞여 있다(09장, vh, axf). 3자리 절단 vs 반올림의 차이. 파생 무관 → 표시 전용 교정 후보.

### 1.4 발견 C — 교차참조 사멸 (가독성·항행성 저하의 핵심)
- 정상 `xref` 링크(`/physics/<slug>/#hub:…`, `class="xref" data-ref`)는 **206개**.
- 그러나 본문 텍스트의 `§X.Y` 형식 포인터는 **724회** 등장. 상당수가 클릭 불가한 죽은 텍스트.
- 원인: 단일 문서 시절의 절(節) 번호가 슬러그 디렉터리 구조로 분할되며 다수가 링크로 변환되지 않음.
- **다행인 점**: 링크 인프라(허브 앵커, `data-ref`)가 이미 존재한다. 즉 **변환만 하면 되는** 문제이지 설계 부재가 아니다.


### 1.6 발견 E — 게이트·메타 인프라가 이미 존재
- `reports/`에 `phase1/2/3-physics.gate.json`, `content-audit-physics.json`, `fix_residues.report.json`, `STATUS_physics.md` 존재 → **재실행·회귀 비교 가능**.

## 4. 실행 단계와 순서

각 Phase는 LOCK → Derive → Gate를 따르며 차선(lane)을 침범하지 않는다.

- **Phase 0 (완료)**: 1차 정찰 — 본 문서 §1.
- **Phase 1**: V1 + V2 전수 감사(수치/SSOT/DAG/교차참조). 산출 = FAIL/WARN 목록.
- **Phase 2**: 판정 분류 — 발견을 §0.3의 표시 전용 vs 버전 필요로 나눔. 표시 전용(반올림·기준선 라벨, 발견 A·B·C)은 즉시 교정 묶음으로. 파생 영향 항목은 new `lock_id` 제안서로.
- **Phase 3**: V3 + V4(가독성·게이트) + 보완 S3.
- **Phase 5**: 보완 S2(프런티어). 자원 게이트 항목(α_em·g)은 별도 장기 트랙.
