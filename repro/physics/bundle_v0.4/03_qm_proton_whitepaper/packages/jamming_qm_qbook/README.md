# 재밍 격자 기반 양자역학 패키지 (초안)

이 패키지는 사용자의 재밍 격자 우주론, 82+7 핵자 구조, 그리고 유체역학적 길이 선택 모델을 바탕으로
`양자역학 교과서급` 이론을 수치적으로 재현하기 위한 최소 골격입니다.

구성:

- `code/proton_radius_model.py`
    - 연속체 회전 모형과 콤프턴 길이에서 양성자 반지름을 계산.
    - 무차원 압력 `p_in ~ x^-4`, `p_stiff ~ α x^-5`를 사용해 균형점 `x* = α = 2/π`를 확인.
- `code/proton_shell_mc.py`
    - 7개 껍질 유닛이 격자 위에서 상쇄/생존하는 간단한 몬테카를로 예제.
    - 문서에 제시된 `[-2, 0, -2]` 생존 벡터 구조를 재현하도록 후속 튜닝을 위한 뼈대.
- `code/electron_one_second.py`
    - 전자 사건 시퀀스 {n_k}와 tick 시간 Δt로부터 전자 1초를 재구성하는 로직 골격.
- `docs/qm_textbook_outline.md`
    - 재밍 격자 기반 양자역학 교과서(초안)의 장별 목차와 계층 구조.

이 패키지는 DOI를 이미 부여받은 것은 아니며, 사용자가 로컬에서 수정·보완한 뒤
압축/업로드하여 별도 DOI를 신청하는 것을 전제로 합니다.
