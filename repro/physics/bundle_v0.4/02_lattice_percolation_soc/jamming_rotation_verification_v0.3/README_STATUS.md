- (3) **n-fold 법칙**: 회전쌍당 율 1/δ=π²; ν_n=n·(1/δ)^(n−1)=n·π^(2(n−1)); n=3 → **ν_p=3π⁴=292.23 s⁻¹.**
- (4) **사슬 닫힘**: 2π=α/δ; m_p/m_e=6π⁵=2π·ν_p=1836.118(측정 1836.153, **−19ppm**); D=2λ_Ce=4.8526pm.
- **★ 회전 경로 완결(g₀ 없음):** 회전이 길이를 낳고(rotation_sweep) → 정류가 2/π 고정(stiffness_size) → C₃ 정준율 3π⁴가 절대 스케일 고정(이 모듈; m_p/m_e=6π⁵=2π·ν_p → 콤프턴 → D=4.85pm). 증폭 경로의 조정 g₀ 불필요.
- 정직: 적분(α,p,δ)·n=3 필연은 *유도*; n-fold 조립((n−1)쌍)은 백서 정류법칙을 *검증·조립*. m_p/m_e −19ppm.
- 실행: `python3 canonical_rate.py`
