# VP Jamming/Rotation Program — 완결 보고서 (외부 검증용)

이 작업은 VP(Volume Particle) jamming 기질에서 **양성자/양자 길이 4.85 pm**와 **양성자 구조 82=81+1**가
회전·jamming 기하에서 어떻게 나오는지를 시뮬레이션으로 검증한 것이다. 외부 검증의 신뢰를 위해
**각 결과의 주장 등급을 먼저 명시**한다.

---

## 주장 등급 (claim levels)

- **[A] 파라미터-프리 (정확 / CODATA):** 피팅된 모수가 전혀 없음. 닫힌 형식 상수, 정수 격자 카운트,
  또는 CODATA 값만 사용. 외부에서 즉시 재현 가능. → `final_verification.py`
- **[B] jamming에서 측정 (시뮬, 튜닝 없음):** jamming 시뮬에서 자기-조직화로 *측정*된 양 (예: c²=K).
  모수 피팅 없음.
- **[C] 정성적 동역학 (시뮬, 자기-일관성):** crude MD가 자기-일관성을 확인하나, 정량적 정밀 결과는 아님.
- **[D] 풀 엔진 영역 (이 작업 범위 밖):** C₃/노즐 격자 기하가 필요 — 등방 MD로는 *원리상* 불가.

---

## [A] 핵심 파라미터-프리 결과

### A1. 직교 정류 적분 (rectification)
회전 성분의 방향 평균. 모두 닫힌 형식:
- α = ⟨|cosθ|⟩ = **2/π** = 0.636620
- p = ⟨[cosθ]₊⟩ = **1/π** = 0.318310
- δ = p·p = **1/π²** = 0.101321
- 일관성: α/δ = **2π**

### A2. 정준 C₃ 회전율과 질량비
n=3은 *중심을 감싸는 최소 양성-생성 집합*(positively-spanning, 위상적으로 강제). n-fold 율
ν_n = n·π^(2(n−1)) (n 방향 × (n−1) 회전쌍):
- **ν_p = 3π⁴ = 292.227** — 이것이 양성자 분쇄율("초당 292개").
- **m_p/m_e = 6π⁵ = 2π·ν_p = 1836.118** (CODATA 1836.153, **−19 ppm**).

### A3. 양성자/양자 길이 D = 4.85 pm — 세 독립 경로
- 전자 경로: D = 2·λ_Ce = **4.8526 pm**
- 양성자 경로: D = 6π⁶·r_p = **4.8523 pm**
- 강성 경로: r* = (2/π)·λ_Cp = **0.8412 fm** (= CODATA r_p), D = 6π⁶·r* = **4.8525 pm**
- **경로 간 편차 0.006%.**

강성 경로의 의미: jamming/회전의 강성-균형(정류된 강성 ~r⁻⁵ vs 유입 ~r⁻⁴)이 *유일한 안정 교차*
x* = α = 2/π를 강제 → r_p = (2/π)λ_Cp. 회전이 길이를 낳고(x*~1/Ω; 정준 Ω에서 유입계수 1 → x*=2/π),
정류가 2/π를 준다. (백서 §11.6.4 "stiffness selects size".)

### A4. 양성자 코어 격자 (순수 정수 기하)
- 3D: 81 = #{(x,y,z)∈ℤ³ : x²+y²+z²≤6} = **3⁴**. +1 노즐 → **82**.
- 2D 유사물: #{x²+y²≤6} = **21** (시뮬의 2D 검증에 사용).

### A5. 통합 — 하나의 정준수
양성자의 **분쇄율**(ν_p=3π⁴), **질량비**(6π⁵=2π·ν_p), **크기**(4.85 pm, 6π⁶/Compton 경유)가
모두 동일한 정준수 계열로 묶인다. 분쇄 동역학·질량·크기가 ν_p=3π⁴ 하나에서 나온다.

## [B] jamming keystone (시뮬, 튜닝 없음)
**c² = K** (집합 강성). 강성은 jamming 가지(M1)에서 φ가 ~0.64로 자기-조직화하고 z→6(isostatic)일 때
*측정*된다. c는 창발적 탄성파 속도 (c² = B_eff/ρ_eff, 백서 §10.1, §11.6.1). 모수 피팅 없음.
- **82=81+1 입방 격자는 isostatic** (내부 z = 6 = 2d) → 강성 K=c²를 운반 → A3 강성 경로가 접지된다.
- (`vp_lattice.py`, `wavelength_jamming.py`)

---

## [C] 양성자 형성 동역학 (정성적, 자기-일관성)
역회전(0.6c) + 수축 + 밀도-1 + 분쇄 + **외부 보충** = 정상상태 분쇄기, **붕괴 없음**. 핵심 정성 결과:
- **강성-균형의 필수성:** 강성만 → 크기 선택 안 됨(임의); 수축+분쇄만(보충 없이) → *폭주 붕괴*(N→0);
  *둘의 균형*에서만 안정. **이 동적 균형점이 정적 r* = (2/π)λ_C와 일치** — 정적·동적 결과의 교차 검증.
- **분쇄율 = ν_p = 3π⁴** (정준율). 외부 보충이 소멸을 상쇄 → 정상상태.
- (`proton_contract.py`: 무파괴 깨끗한 밀도-1 수축; grinder/replenish 계열: README 참조)

## [D] 풀 엔진 영역 (범위 밖 — 정직한 한계)
**정확한 82-균일 결정 구조는 등방 수축으로 나오지 않는다 — 파라미터 문제가 아니라 원리.**
동일 구의 *등방* 수축은 **비결정(amorphous) 무작위 충전**(크기 번짐, churning, z~6–12)을 주지만,
양성자는 **결정(R²≤6 격자)**이다. 결정화는 *방향성*(C₃ 축/노즐)이 templating 해야 일어나며,
그것이 풀 물리 엔진(백서 §8.0.5)의 일이다.
- 검증: 크기로 세도(진동 카운팅 회피) 압축 영역은 ~108개로 *번져* 있을 뿐,
  "82 균일 + 7 작음" 띠가 crude MD에 *없음*. → 결정 구조는 격자 기하에서만.

## 정직한 미해결 항목 (외부 검증 시 명시 권장)
1. **절대 척도의 앵커:** 4.85 pm의 *무차원* 내용(2/π, 6π⁶ 등)과 강성 c²=K는 jamming/회전에서 나오나,
   *절대 pm*은 Compton 파장(λ_C = h/mc)을 앵커로 들어온다. "jamming 단독"이 아니라
   **"jamming(c²=K) + 운동학적 Compton 사슬"**. 세 경로의 0.006% 일치는 본질적으로 m_p/m_e≈6π⁵를 반영.
2. **증폭 경로의 튜닝:** 백서 §10–11의 대안 경로 D = 2πλ/A는 g₀≈2×10⁻⁷에 *튜닝*된다
   (격자에 그런 스케일 없음; 최소 기하 throat gap ≈ √2−1 ≈ 0.414). **파라미터-프리 아님** —
   강성/회전 경로(A3)가 깨끗한 경로다.
3. **−19 ppm:** 6π⁵ vs CODATA m_p/m_e의 −19 ppm 잔차 (정확한 정수-π 관계의 미세 편차).
