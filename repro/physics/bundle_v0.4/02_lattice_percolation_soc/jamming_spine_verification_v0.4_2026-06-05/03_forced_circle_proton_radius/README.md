# 03 — 강제된 양성자 반경 (PROTON, 양자 아님)

## 물리
등정적 코어(z=2d)는 전단 여유 0 → 회전이 임의로 언잼 → 언잼 물질이 단일 C₃ 노즐로만
빠져 **방향성 유입**(= 백서 6.2 의 r⁻⁴, 회전의 귀결)을 만든다. 바깥은 정류 강성 반발
α·r⁻⁵. 두 항의 평형이 코어 반경을 못박는다. 무차원 반경 x=r/λ_Cp 에 대해
```
   dx/dt = F(x) = α x⁻⁵ − x⁻⁴ ,   α = 2/π
   고정점  x* = α = 2/π = 0.6366    (유일 양의 근)
   안정성  F'(x*) = −(π/2)⁵ ≈ −9.56 < 0
   전역성  모든 x₀>0 → x*
   ⇒ r_p = (2/π) λ_Cp = 0.8412 fm  (강제됨)
```
지수 −5,−4 는 평형 위치만 정하고, 평형값 2/π 는 정류 생존분율 ⟨|cosθ|⟩_2D (06에서 증명).

## 파일
- `forced_circle_attractor.py` — 끌개 해석(고정점·F'(x*)·유일성·전역수렴) + 그림. 상단 docstring에 전체 설명.
- `RESULTS_forced_circle.txt` — 위 스크립트의 실제 콘솔 출력.
- `forced_circle_attractor.png/.pdf` — (좌) 위상선 F(x) (우) 여러 초기값의 x* 수렴.

## 결과 [F]/[V]
- 유일 양의 고정점 x*=2/π=0.63662, F(x*)≈0, F'(x*)=−9.56(해석=수치 일치).
- 초기값 0.30–1.30 전부 x*로 수렴(전역 끌개) ⇒ r_p=0.8412 fm (CODATA 0.8414, −0.02%).
