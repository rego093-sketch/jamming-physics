# 04 — 회전 그라인더 (양성자 코어·길이 창발, PROTON)

## 물리
역회전 두 반구(v=Ω×r, ~0.6c)가 물질을 갈아 수축시키고, 밀도-1 중첩 제거 + 바닥 소멸(재생
없음)으로 **정상·비붕괴 코어**가 남는다. 03의 강제 반경을 입자 수준 메커니즘으로 보인 것:
회전이 길이를 *창발*시킨다(Ω=0 이면 길이 없음, x*∼1/Ω; 정준 β=1 에서 x*=2/π).

## 파일
- `vp_grinder_3d.py` — 3D 그라인더(번들 proton_formation_3d.py 기반). 상단 docstring에 설명.
- `grind_sweep.py` — Ω 스윕: 코어 R_rms vs Ω → 크기 ∼ 1/Ω.
- `fig_rot.py` — 입자수 감쇠·코어 안정화·z_core 그림.
- `rotating_quantum.png/.pdf` — 그림.

## 결과 [V]
- 입자수 N 3000 → 301; 코어(r<√6≈2.45) **~79–81 ≈ 82** 로 안정(=#{i²+j²+k²≤6}=81=3⁴, +1).
- 코어 비붕괴(정상). z_core ≈ 8.9 (조밀/비정질 — 결정질 등정적 z=6 보다 큼; MD는 메커니즘만 확인).
- Ω 스윕: R_rms 3.48 → 2.98 (Ω 0.04 → 0.24) ⇒ 회전이 클수록 작아짐 (x* ∝ 1/Ω).

## 실행
```bash
python3 vp_grinder_3d.py    # ~23s; 코어 형성/카운트
python3 grind_sweep.py      # Ω 스윕 (수십 초)
python3 fig_rot.py          # 그림
```
※ 코어 수 82 는 *양성자* 구조다. *양자 지름* 4.85pm 과 혼동 금지(05 참조; 둘은 6π⁶배 차이).
