2) n-겹 사다리 [D] (정의 MAP-1: 섹터 lock 1개 = 1/delta = pi^2 — 이 한 점에만 의존)
==============================================================================
  1/delta                = 9.869604  (= pi^2)
  nu_p = n*(1/delta)^(n-1), n=3 = 292.227273  vs 3*pi^4 = 292.227273
  m_p/m_e = 2pi*nu_p     = 1836.118109  vs 6*pi^5 = 1836.118109
     CODATA m_p/m_e      = 1836.152673   ->  편차 -18.8 ppm
  D/r_p = pi*(m_p/m_e)   = 5768.3352  vs 6*pi^6 = 5768.3352
  => 6*pi^6 은 독립 상수가 아니라 6*pi^5(질량비)의 변장. '6*pi^6 증명' = '6*pi^5 증명' = MAP-1 한 점.

3) 양성자 vs 양자 스케일 분리 (절대 혼동 금지)
==============================================================================
  양성자 r_p = (2/pi)*lambda_Cp = 0.8412 fm   vs CODATA 전하반경 0.8414 fm (-0.02%)
  양자  D   = 2*lambda_Ce       = 4.8526 pm   (= 2 lambda_Ce)
  D / r_p                       = 5768.44   vs pi*(m_p/m_e) = 5768.44, 6*pi^6 = 5768.34
  => 양성자(10^-15 m)와 양자(10^-12 m)는 *다른 객체*, 6*pi^6(~5768)배 떨어짐. D 는 '양자 지름'.

==============================================================================
4) 4.96 vs 4.85 (분포 offset — 근본 오류 아님)
==============================================================================
  ell_rot = 2*pi*lambda_light/A  (lambda_light = 633 nm)
  목표 D = 2*lambda_Ce = 4.8526 pm  를 주는 A_target = 8.196e+05
    bundle A 중앙값                 A=8.010e+05 -> ell_rot=4.965 pm  (목표대비 +2.3%)
    독립 SOC A 중앙값(본 세션)           A=7.160e+05 -> ell_rot=5.555 pm  (목표대비 +14.5%)
  => A 분포 중앙값이 목표보다 낮으면 ell_rot 가 높게 나옴(+%). 데이터 분포는 05/ellrot_verify.py 참조 (중앙값 ~4.96 pm, best ~4.854 pm).

==============================================================================
5) 정수 코어 + 정상모드 기하
==============================================================================
  2D  #{ i^2+j^2     <= 6 } = 21        (2D 유사)
  3D  #{ i^2+j^2+k^2 <= 6 } = 81  = 3^4 = 81   (양성자 코어 82 = 81+1)
  정적 정상모드라면 D/lambda = (k R_1)/pi:
    l=0  첫 영점 x_1 = 3.14159  ->  D/lambda = 1.000
    l=1  첫 영점 x_1 = 4.49341  ->  D/lambda = 1.430
    l=2  첫 영점 x_1 = 5.76346  ->  D/lambda = 1.835
  반례 처리: 양자는 *회전체*(그라인더). 정적 모드(l=1->1.43)가 아니라 회전 둘레 2*pi 가 길이
            => D = 2*pi*lambda/A. 정적 1.43 과 다른 메커니즘.
