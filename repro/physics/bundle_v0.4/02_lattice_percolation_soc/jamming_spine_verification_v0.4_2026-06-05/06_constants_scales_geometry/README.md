# 06 — 상수·스케일·기하 (순수 수학 검증)

## 무엇
시뮬이 아니라 적분/대수/격자 셈. 어느 기계에서도 같은 값. "닫힌 형태로 증명된 것 [F]"과
"정의(MAP-1)에 기댄 것 [D]"을 한자리에서 가른다.

## 파일
- `verify_constants_and_scales.py` — 아래 5블록을 계산·출력. 상단 docstring에 식·등급 전부.
- `RESULTS_constants_and_scales.txt` — 실제 콘솔 출력.

## 다루는 것 / 결과
1. **각도 상수 [F]**: α=⟨|cosθ|⟩_2D=2/π=0.63662; ⟨[cosθ]₊⟩=1/π=0.31831 → δ=1/π²=0.10132;
   ⟨|cosθ|⟩_3D=1/2; **2π = α/δ = 6.28319** (두 증명된 적분의 비).
2. **n-겹 사다리 [D]**: 1/δ=π²; ν_p=3π⁴=n·(1/δ)ⁿ⁻¹(n=3)=292.227; m_p/m_e=2π·3π⁴=6π⁵=1836.118
   (CODATA 1836.153, **−18.8 ppm**); D/r_p=π·6π⁵=6π⁶=5768.34.
   ⇒ **6π⁶ 은 독립 상수가 아니라 6π⁵(질량비)의 변장.** '6π⁶ 증명'='6π⁵ 증명'=[MAP-1] 한 점.
3. **스케일 분리**: r_p=(2/π)λ_Cp=0.8412 fm; D=2λ_Ce=4.8526 pm; D/r_p=5768=π·(m_p/m_e).
   ⇒ 양성자(10⁻¹⁵ m)와 양자(10⁻¹² m)는 6π⁶배 떨어진 다른 객체.
4. **4.96 vs 4.85**: A_target=8.196×10⁵; A 중앙값이 낮으면 ℓ_rot +% (분포 offset; 데이터는 05).
5. **정수 코어 + 정상모드**: 3D #{i²+j²+k²≤6}=**81=3⁴**(코어 82=81+1); 2D=**21**;
   구면 베셀 첫 영점 → 정적 D/λ(l=0,1,2)=1.00/1.43/1.83. (반례: 양자는 회전체라 2π 둘레가 길이, 정적 1.43 아님.)

## 정직한 결론
[F]: 2/π, 1/π, δ=1/π², ⟨|cosθ|⟩_3D=1/2, 2π=α/δ, 코어 81=3⁴·21, 베셀 정적비.
[D]: 3π⁴→6π⁵→6π⁶ 전부 [MAP-1]("섹터 lock=π²") 한 점에 의존(α·δ와 동일 지위). 억지 유도 금지.
