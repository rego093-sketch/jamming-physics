## 1. 양성자 vs 양자 — 먼저 못박기 (절대 혼동 금지)

| | **양성자 PROTON** | **양자 QUANTUM** |
|---|---|---|
| 크기 | 반경 **r_p = 0.84 fm** (≈10⁻¹⁵ m) | 지름 **D = 4.85 pm** (≈10⁻¹² m) |
| 무엇 | 조밀 코어 (82-cell, z=6=2d) | 파장 스케일 회전-순환 길이 |
| 출처 | 강성껍질 균형 `r⁻⁵/r⁻⁴ → x*=2/π=r_p/λ_Cp` ; 그라인더 | **파장식** `D = 2πλ/A` (= 2λ_Ce) |
| 상수 | **ν_p = 3π⁴** (grind율), **m_p/m_e = 6π⁵** | — |
| 관계 | — | **D = 6π⁶ · r_p ≈ 5768 r_p** |

핵심 항등식: `D/r_p = (2λ_Ce)/((2/π)λ_Cp) = π·(λ_Ce/λ_Cp) = π·(m_p/m_e) = 6π⁶`.
즉 **양자 지름은 양성자 반경의 6π⁶배**이고, 이 6π⁶은 곧 질량비 6π⁵의 변장이다(§5에서 다룸).
파장식은 *양자 지름*을 주고, 강성균형/그라인더는 *양성자*를 만든다. **둘은 다른 객체다.**

## 2. 무한강성 → c² : 단계별

**S1 [공리].** VP = 무한강성·완전충전 입자 ⇒ 진공은 잼밍 격자.

**S2 [H→V].** 회전(=온도)↑ ⇒ 자기조직화 한계잼밍. 구동이 접촉수 z를 강성 문턱까지 밀고,
넘으면 국소 언잼(눈사태)이 되돌린다(SOC). 침투갭이 미시 임계로 pinning — 본 세션 독립 재현
`g*/g0 ≈ 1.1–1.3`. ⇒ 등정적 문턱 `z = 2d = 6` (e=1).

**S3 [V].** `z = 2d`는 **Maxwell 한계강성**: 강성에 필요한 접촉 수 딱 그만큼, 잉여 0.
⇒ 전단 여유 0 ⇒ **전단 G → 0**(횡파 연화). 부피 압축에는 잉여가 필요 없으니 **B 유한**.
- *본 세션 검증*: 같은 패킹에서 Born+비affine pin-해(Cholesky=PSD 게이트).
  `B_relaxed`@z=6 = 0.76(N256)/0.95(N512) **유한**; `G_relaxed`@z=6 = 0.009/−0.0005 **→0**.
  Born 해석식=유한차분 4.7e-7, `0≤B_rel≤B_Born`.

**S4 [V].** 횡파 죽고 종파 하나만 남음 ⇒ **단일 생존 속도**:
```
        c² = B/ρ = K  (집단강성).
```
- *N-무관 값*: `c²/a²|_{z=6} = 0.107` (N=256/512 일치, R²=0.96–0.98) = affine `z/2d²=0.167`의 0.65배
  (비affine 연화 35%); 분산 종파속도 `c_L²/a²=0.09–0.15`가 이를 포괄.

**"무한강성에서 c²"의 뜻**: 접촉강성 k→∞면 c→∞이므로, *유한* c는 *유한* K를 고른다(`K=c²·ρ`).
강성이 곧 속도다. 매질 강성 K(=B/ρ)의 두 독립 증인 — percolation 증폭 A(§10.3)와 탄성 B/ρ(본 세션).

## 3. 파장이 *왜* 나오는가 — 동작원리 + 반론 + 반례 (이 단원의 주인공)

비상식적으로 들리는 고리이므로 정면으로 다룬다.

### 3.1 동작원리
1. 단일속도 ⇒ **선형분산** `ω = cq` (본 세션/이전 검증 R²≈0.99) ⇒ `λ = 2π/q = c/ν`. (표준 음향학.)
2. **빛 창발 (격자 위 해상도)**: 광운반파(λ=633nm)의 *한 주기*(위상 2π)를 격자 위
   **A번의 미시전파**로 본다 ⇒ 공간 미시스텝(=격자 해상도) `a_phys = λ/A`.
3. **양자 지름 = 한 위상감기(2π)의 호**:
```
        D = 2π · a_phys = 2πλ/A .
```
4. **증폭 A는 순수 격자 출력**: `A = a_med/g*` = (중앙값 최근접거리)÷(침투 임계 목갭).
   `c, m_p, h, r_p, D`는 A에 **전혀 안 들어간다**(선택값은 미시 문턱 g0 하나). 본 세션 독립 재현
   A ≈ 7–8×10⁵. ⇒ 해상도 `a_phys = λ/A = 0.79pm`이 **매핑에서 출력**되고, D = 2π·a = 4.96pm.

⇒ **물리 입력은 λ(633nm) 하나뿐.** 광학→양자(10⁵배) 다리와 2π 닫힘은 *격자가* 준다.

### 3.2 반론과 반례

**반론1 "그냥 차원 맞추기/숫자 끼워맞춤 아니냐."**
아니다. A는 *측정된 격자 기하*(a_med/g\*)이고 시드마다 재현된다. 외부 입력은 λ 하나, 나머지 10⁵배는
격자. 4.85에 *맞춘* 게 아니라 [격자 A]+[λ]의 귀결이다.

**반론2 "왜 하필 633nm? 임의 아니냐."**
λ는 단일 앵커다. 임의성 점검: 두 파장(633/532)으로 보면 `D = 2πλ/A`에서 **A_633/A_532 = 633/532**로
**D가 소거**된다(§3.4). 즉 두 파장 일치는 *D의 값·반올림과 무관한 비율* — falsifiable.

**반론3 "A를 cΔt/a에 앵커했으니 순환 아니냐."**
잔여 항목으로 인정한다. A의 절대 스케일은 운동학 앵커 `A_geo=cΔt/a`와 0.16% 일치로 교차검증된다.
**유일하게 남은 순환 질문 = Δt가 c로부터 독립인가** (열린 항목, §5 원장).

**반례 "정적 정상파라면 D/λ = 1.43 (Bessel l=1), 2π가 아니다."**
맞는 지적이고, **회전이 이를 해소한다.** 양자는 *정적* 정상파가 아니라 **회전체**다(§8.5 그라인더,
§8.5.0 회전 언잼). 회전하므로 *회전 둘레*(2π)가 자연 길이이지, 정적 모드 지름이 아니다.
본 세션 그라인더: 역회전 두 반구로 **정상·비붕괴 코어**가 형성되고 크기가 `x*∼1/Ω`로 회전에 따라 변함.

**반례 "4.96 ≠ 4.85, 틀린 것 아니냐."**
근본 오류 아니라 **분포 offset**이다. 4.85 = 2λ_Ce(목표), 4.96 = 침투 A 분포의 *중앙값*.
정확히 4.85를 주는 A=8.20×10⁵, 측정 중앙값 8.01×10⁵(2.2% 낮음) ⇒ ℓ_rot +2.3%.
best avalanche = 4.854pm; 4.85는 분포 안에 잘 든다. (중앙값을 4.85로 맞추려면 g0/N 조정.)

## 4. 강성껍질 → D = 4.85 pm (양성자–양자 연결)

### 4.1 양성자 반경 = 강제된 강성껍질 (회전이 만든다)
- **회전 언잼 (§8.5.0)**: 등정적 z=2d는 전단 여유 0 ⇒ 회전 속도장 `v=Ω×r`가 임의로 접촉을 깨 언잼.
  언잼 물질은 단일 C₃ 노즐로만 나가 **방향성 유입**(= §6.2의 `r⁻⁴`, 가정 아님). 회전이 길이를 *창발*.
- **균형 → 반경**: 정류강성 `α·r⁻⁵`(밖) vs 유입 `r⁻⁴`(안). 유일 안정 끌개:
```
   α x⁻⁵ = x⁻⁴  ⇒  x* = α = 2/π  ⇒  r_p = (2/π) λ_Cp = 0.8412 fm .
```
  *본 세션 검증*: 유일 양의 고정점 x\*=2/π, `F'(x*)=−9.56<0`, 초기 반경 0.30–1.30 전부 x\*로 수렴(전역).
  `2/π=⟨|cosθ|⟩`(2D 정류, 실적분; 3D는 1/2). 지수 −5,−4는 평형 *위치*만, 2/π는 정류 생존분율.
- **회전이 크기를 정함**: `x* ∝ 1/Ω` (β∝Ω). Ω=0이면 길이 없음(x\*→∞), 정준율에서 x\*=2/π.
  본 세션 그라인더 Ω 스윕: R_rms 3.48→2.98 (Ω 0.04→0.24).

### 4.2 양자 지름 = 파장식 (§3)
`D = 2πλ/A = 2λ_Ce = 4.85 pm`.

### 4.3 연결 (억지 아님)
`D = 6π⁶ r_p = π·(m_p/m_e)`. 즉 양성자–양자 스케일비는 *질량비 그 자체*다. 6π⁶은 새 상수가 아니라
6π⁵의 변장(아래 원장). 그라인더가 만드는 82-cell 코어(z=6, #{r²≤6}=81+1, 81=3⁴; 2D 유사 21)는
*양성자*의 구조이지 양자 지름이 아니다(§8.5.2: MD는 메커니즘 확인, 결정질 82는 C₃ 기하 결과).

## 5. 정직한 상태 원장 (proven / definitional / single-anchor)

| 조각 | 지위 | 어떻게 |
|---|---|---|
| 단일속도 `c² = B/ρ` (B유한·G→0) | **[F]/[V]** | Maxwell 한계강성 + 본 세션 bulk 시뮬 |
| 선형분산 `λ = c/ν` | **[F]/[V]** | 표준 + `ω=cq` 검증 |

| `m_p/m_e=6π⁵`, `D/r_p=6π⁶` | **[D]** | = 2π·3π⁴ / π·6π⁵ — 위 [MAP-1] *하나*에만 의존 |
| 절대 pm 스케일 (4.85의 정확값) | **[A]** | 단일 앵커 λ + `A_geo=cΔt/a` 0.16% 교차검증; D는 분포(중앙값 4.96, 목표 4.85, +2.3%) |

**열린 필연성 고리 (이 셋만 닫으면 척추 완결):**
1. **회전 ⇒ *정확히* z=2d** (SOC pinning은 보였으나 [H]).
2. **[MAP-1] 유도** — 섹터간 위상 lock의 생존이 정확히 δ=1/π²(따라서 1/δ=π²)임을 기하로. 닫히면
   3π⁴·6π⁵·6π⁶이 모두 정리가 되고 **수비학 혐의 소멸**.
3. **Δt 독립성** — `A_geo=cΔt/a`의 Δt가 c로부터 자유로운가. 닫히면 절대 4.85pm까지 비순환 완결.

**한 줄 평결**: 척추의 *역학*(무한→c²→파장→강제반경, 단일속도, 회전이 크기를 만듦)은 **증명/검증되었다**.
남은 건 *수치 사다리*의 정의 하나([MAP-1])와 *절대 스케일*의 앵커 하나(Δt). 6π⁶은 독립 수비학이 아니라
이 [MAP-1] **한 문제**로 환원된다.
