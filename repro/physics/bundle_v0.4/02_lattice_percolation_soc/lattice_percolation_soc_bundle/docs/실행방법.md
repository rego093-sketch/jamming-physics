# 실행 방법

## 요구사항
- Python 3.10+ 권장
- numpy, matplotlib
- (추가) pandas: 회전 스케일 분석(`code/jamming_rotation_485pm_study.py`)에서 사용

설치:
```bash
pip install -r requirements.txt
```

## 전체 실행(결과/이미지 재생성)
`code/run_all.py` 를 실행하면
- 2D 토이(목 임계)
- 3D 재밍 격자에서 g* 추출/스윕
- SOC 퍼콜레이션 핀닝
- MST 단위 구현/교차검증(633/532 nm)
- 가시광선 캐리어(파동) 데모
- (추가) 재밍 떨림의 회전 스케일(4.85 pm) 분석
을 순서대로 수행하며 `results/`, `images/`에 파일을 저장합니다.

```bash
python code/run_all.py
```

## 개별 실행

### MST 단위 구현/교차검증만
```bash
python code/mst_optionb_unit_realization.py
```

### 가시광선 캐리어(파동) 데모만
```bash
python code/lattice_visible_wave_emergence.py
```

### 회전 스케일(4.85 pm)만
```bash
python code/jamming_rotation_485pm_study.py
```

※ 재밍(에너지 최소화) 단계는 계산량이 있어, N과 반복수에 따라 실행시간이 달라집니다.
