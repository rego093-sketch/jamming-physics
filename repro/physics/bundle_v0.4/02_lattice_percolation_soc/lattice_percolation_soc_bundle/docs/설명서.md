# 격자(재밍) 기반 임계 퍼콜레이션(SOC)으로 δ_eff/a ~ 1e-6, A~1e6를 뽑는 시뮬 패키지

이 번들은 대화에서 사용한 핵심 아이디어를 “코드 + 결과(CSV) + 이미지 + 설명서”로 묶은 것입니다.

## 핵심 정의(기하학 + 뉴턴 + 탄성, 상대론 없음)

- 3D 주기경계 박스(크기 L=1) 안에 동일 반지름 R의 구(N개)를 배치.
- 재밍(jamming) 근처에서 “조밀한 기하 구조”를 만든 다음, 격자(그래프)로 해석.

### 1) 목갭(Neck gap)
이웃 i→j 에지에서
- 중심거리: d_ij
- 목갭: g_ij = d_ij - 2R

### 2) 유효 목갭 δ_eff := g*
“가장 작은 갭”이 아니라, **전역 전파를 실제로 담당하는 임계 목**을 잡기 위해
- ‘빠른 에지’ 조건: 0 < g_ij <= g_cut
- 소스(src)에서 출발했을 때, 멀리 있는 노드(FAR)의 일정 비율(예: 0.8)이 도달 가능해지는 최소 g_cut를 g*로 정의
- δ_eff := g*

즉,
- δ_eff/a ≈ g*/a_med
- A := a/δ_eff = a_med/g*

여기서 a_med는 kNN(기본 12) 거리의 중앙값(격자 스텝 스케일)입니다.

### 3) 속도 스케일
목 통과 시간 스케일을 Δt ~ δ_eff / v0 로 두면

c ~ a/Δt = v0 * (a/δ_eff) = v0 * A

(이 번들에서는 v0=1 단위로 수치 시그니처를 측정하며, SI(m/s)로 바꾸려면 v0를 물리 속도 스케일로 캘리브레이션하면 됩니다.)

## SOC(자기조직화 임계 퍼콜레이션) 선택원리
ε(재밍에서 얼마나 풀었는가)가 0으로 계속 내려가면 δ_eff→0, A→∞로 발산할 수 있습니다.
SOC는 다음의 음의 피드백으로 시스템을 임계점 근처에 붙여서 δ_eff를 유한값에 고정(pin)시키는 메커니즘입니다.

- 느린 드라이브: ε를 천천히 감소(압축) → 목갭이 작아져 ‘빠른 에지’가 늘어남 → 퍼콜레이션 임계에 접근
- 임계 도달(예: FAR 80% 도달): 전역 연결이 생기면 큰 재배열(눈사태)이 발생
- 눈사태: 연결 클러스터에 작은 랜덤 킥 + 간단한 에너지 최소화(겹침 제거) → 평균적으로 목을 다시 벌림 → ε가 증가(완화)

결과: 시스템은 반복적으로 임계를 건드렸다가 튕겨나오며, δ_eff가 특정 밴드에 머무는 현상을 보입니다.
