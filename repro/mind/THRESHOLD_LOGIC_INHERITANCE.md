# THRESHOLD-SHIFT INTERVENTION LOGIC — 상속 및 기존 사례 적용 계획

> **문서 성격.** 이 문서는 한국어(세션 언어) **거버넌스 문서**다. 백서 본문(`docs/` HTML, 예: §30)은
> VP-SPEC C0에 따라 **영어 전용**이다. 이 문서는 (1) 진통(analgesic) 패키지에서 가져온 **문턱-이동
> 개입 논리(threshold-shift intervention logic)** 기술을 mind 패키지의 **횡단(cross-cutting) 재사용
> 층**으로 공식 상속하고, (2) v1.37에서 양극성(§30)에 **능동 적용**한 결과를 기록하며, (3) 이미 출판된
> 기존 질환 모듈들(뇌전증·조현병·우울·자폐·ADHD)에 이 논리를 **적용할 계획**을 — 사용자 지시
> "기존 연구사례에도 적용을 계획하라" 에 따라 — 등록한다.

## 0. 한 줄 요약

증상 = **발화 문턱(firing threshold)을 넘는 것**, 개입 = 그 문턱을 **통제된 방향으로 위로 올리는 것**.
문턱은 전류 균형이 정하므로 손잡이는 **정확히 셋**이다 — **L1** 안쪽(흥분) 전류를 줄임 · **L2** 바깥쪽(K⁺)
전류를 늘림 · **L3** 상류 민감화 구동을 제거. 이 프레임은 mind 패키지 전체가 의존하는 **동일한 R19 기질**
(`ṡ = g·s − s³ + h`, spinodal fold = 스위칭 장벽) 위에서 작동하므로, **새 메커니즘·새 튜닝 상수 0**으로
어떤 질환 모듈에도 부착된다.

## 1. 무엇을, 어디서 상속했는가

- **출처.** 진통 재현성 패키지 `analgesic_threshold_logic v2.0` — **Zenodo DOI 10.5281/zenodo.20733420**.
  거기서는 통증-신호 문턱을 다루고 전압-개폐 나트륨 채널(Na_V) 위에서 검증되었다.
- **상속 단위(재사용 부품).**
  1. **3-레버 프레임** L1/L2/L3 (위 §0).
  2. **DNA 접지된 γ 읽기** — γ = −mean(최근접 이웃 스태킹 ΔG, SantaLucia 1998)를 각 유전자의 **자기
     프로모터 창**(TSS−2000..+500, *Homo sapiens*)에서 읽고, **동결 엔진의 자기 함수**로
     `|h_sp| = spinodal(γ) = 2(γ/3)^1.5`, `barrier = γ²/4` 산출 (엔진 READ-ONLY).
  3. **부담-가중 표적 우선순위** — 선언·인용된 가중치로 **표적**을 순위화 (절대 약물·용량 아님).
  4. **L3 정직성 게이트(fail-closed)** — 모든 L3 링크를 [O] 인용 생물학으로 유지 (유도 금지).
  5. **금지-주장 스캐너(fail-closed)** — 용량·효능·안전·합성 주장 거부 + 자기-테스트 미끼 발화.
  6. **방화벽(비협상)** — 프로모터 |h_sp|는 유전자 **자기 스위치 강성**일 뿐, 채널 활성화 전압·약효·용량·
     생체내 선택성·임상 효과와 **결코** 동일시하지 않는다.
- **코드 수준 재사용의 문자성.** 진통 패키지가 KCNQ2/KCNQ3 칼륨 채널에 대해 읽은 γ 값을 **그대로
  (verbatim)** 가져왔다(같은 유전자·같은 숫자). 엔진은 한 바이트도 건드리지 않으며, 모듈은 동결 트리를
  READ-ONLY로 재-emerge 후 byte-unchanged 확인한다.

## 2. v1.37의 능동 적용 — 양극성 (§30, BIP-T2b-L)

§29의 B4는 "기분안정제 부호 = **장벽 올리기**"를 증명했지만, 안정제를 **단일 추상 연산자**로 취급해
**어떤 유전자·채널**이 장벽을 올리는지는 말하지 않았다. v1.37은 상속된 논리로 그 추상 연산자를
**3-레버 표적 지도**로 분해했다 (16개 양극성 흥분성 유전자):

| 레버 | 의미 | 유전자 (프로모터 γ 읽힘, 공유 스케일) |
|---|---|---|
| **L1** 안쪽 흥분 전류↓ | 스위치로의 구동을 줄임 | CACNA1C(Ca_V1.2, #1 GWAS) · CACNA1D · CACNA1I · SCN2A · GRIN2A; **L1-인접** CACNB2 · ANK3(#2 GWAS) |
| **L2** 바깥쪽 K⁺ 전류↑ | 스위치로부터의 복원을 늘림 | KCNQ2 · KCNQ3 (M-전류 쌍) · KCNB1 |
| **L3** 상류 구동 제거 [O] | 일주기/HPA 민감화 제거 | ARNTL(BMAL1) · CLOCK · PER2 · NR3C1 · CRHR1 · GSK3B (리튬 표적) |

- **결정론·게이트.** 4개 모듈(`bipolar_threshold_levers.py` + L3-정직성 게이트 + 금지-주장 스캐너 +
  부담 우선순위)이 모두 PASS, 2× sha256 동일. `run_all_atlas.py`에 **8번째 아틀라스 시민
  `BIP-T2b-L`** 로 등록 → **ALL PASS 8/8**, 엔진 byte-unchanged.
- **방화벽 가시화.** 우선순위(CACNA1C #1)와 γ/|h_sp| 강성 순위(KCNQ2 #1)가 **분리(decoupled)** —
  강성이 순위를 몰았다면 둘은 그 자리에 있을 수 없다. γ는 구조적 맥락으로만 운반, 점수에 **결코** 합산 안 됨.
- **출판 표면.** 영어 전용 챕터 **§30 「Bipolar threshold levers」** (`docs/mind/30-bipolar-threshold-levers/`),
  레지스터 lock `bipolar_threshold_levers` 추가 → **41 locks / 30 chapters**, `gate.py` **138/138 PASS**.

## 3. 기존 연구사례 적용 계획 (사용자 지시: "기존 연구사례에도 적용을 계획하라")

문턱-이동 논리는 **횡단 층**이므로, 이미 출판된 모든 질환 모듈은 자기 안에 흥분/문턱 구조를 갖고 있어
3-레버 프레임으로 분해 가능하다. 아래는 각 기존 사례에 대한 **계획**(미실행)이며, 각각 (i) 어느 레버가
지배적인지, (ii) 접지할 유전자, (iii) 적합도(fit), (iv) 규율(efficacy=0·L3=[O]·방화벽)을 명시한다.
실행 시 양극성과 **동일 패턴** — γ 캐시 fetch → 3-레버 지도 → L3 게이트 → 금지-주장 스캐너 → 부담
우선순위 → `run_all_atlas.py` 등록 → 영어 챕터 — 을 따른다.
