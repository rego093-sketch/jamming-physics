data for S2). A `[P]` → `[V]` **only here**, on real data, **independent of the child**. Honest negatives kept

**Phase C — Internal deductive-closure test (sharpen; no external data).** For each `[sharpen]`/`[tension]`, run
the **mother's own frozen engine** and ask whether the mother's *stated* mechanism, fully simulated, exhibits the
**same** ceiling/trade-off the child found (S1 depth bound; S2 trade-off). This is an **internal** consistency
check on the mother's deductive closure — non-circular, able to **qualify** the mother's claims without importing
the child as evidence. Where the engine cannot resolve the structure (cf. **W1 / Hard Limit 1** — 12 coarse
nodes, undifferentiated cortical lump), record the obstacle as `[O]` and **defer to the v2 substrate** (which is
also W1's promotion gate). **W1 explicitly motivates the v2 build**: F1 asked for it; the child shows the target
mechanism is real; v2 is where both W1's gate and F1's re-test live.

**Grading.** Every Phase-B/C outcome graded `[V]/[L]/[O]`. Nothing in v1.59 changes a pre-existing grade except
by a Phase-B real-data test or a Phase-C internal-consistency result — **never** by a child confirmation. **v1.59
publishes ONLY**: the `[P]` registrations (Phase A), the `[sharpen]`/`[tension]` qualifications (Phase C where the
engine can run them; otherwise deferred), and the **W1 `[realize]` re-typing** of F1's `[O]`. Every `[P] → [V]`

## 7. Why this is non-circular (the standing rationale, with the third channel)

Two operations on a deductive engine are legitimate theory-building, neither circular:
**deducing untested consequences** the axioms imply but the author never computed (→ predictions, tested
externally — the relativity-implies-gravitational-waves move; `[P]`); and **finding internal inconsistencies**
where a faithful implementation fails to yield an asserted claim (→ falsifies/sharpens; `[sharpen]/[tension]`).
A third operation is legitimate because the child is also an **independent substrate**: **demonstrating that a
mechanism the mother's frozen engine is blind to is nonetheless realizable**, which **re-types an open question**
without answering it (`[realize]`). The **one** illegitimate operation — *citing the engine's confirmations as
evidence for the axioms it was built from* — is **structurally blocked** by §0's hard rule and §6's gate (checks
1, 4, 5). The mother's path to `[V]` runs through **real data only**; the child's path upstream runs through
**predictions, negatives, and realizability re-typings only**. The arrows never close the forbidden loop.
