# CHANGELOG — VP_SPEC v1.8 upgrade

Upgrade of the **Vacuum-Inflow Cosmology** volume (content revision v2.1,
time-sector grounding) from VP_SPEC **v1.6** compliance to VP_SPEC **v1.8**
compliance. The canonical form remains the HTML under `docs/cosmology/`; every
change below was produced by deterministic code in `tools/`, not by rewriting
prose. Source word counts per chapter are invariant (only word-count-excluded
regions were edited).

## Added — Retrieval-Readiness (Constitution C4 / §6-R)

- **Answer-first paragraphs (6-R.1).** Every one of the 28 chapter pages now
  opens, immediately after `<h1>`, with a self-contained `<p class="answer">`
  of 40–60 words built deterministically from the sealed abstract and body text
  (`tools/upgrade_v1_8.py`). The hub carries one too.
- **Self-contained locked-quantity cards (6-R.2).** `aside.vp-card` blocks were
  injected for locked quantities cited on a page but derived elsewhere (value +
  one-line meaning + grade badge + link to the canonical derivation), driven by
  the new locked-quantity registry `tools/cos_locks.json` (42 cards across the
  volume).
- **Enriched JSON-LD (6-R.4).** Each chapter's `ScholarlyArticle` now declares
  `isPartOf` a `CreativeWorkSeries` (identifier = DOI), `author` with ORCID
  `sameAs`, `identifier`, `datePublished`, `dateModified`, `isBasedOn` (repro
  URL) and `knowsAbout`, plus a standalone `BreadcrumbList`. The hub was
  upgraded from `CollectionPage` to `CreativeWorkSeries` (with a 28-item
  `hasPart`) + a standalone `BreadcrumbList`, and gained the 5 Highwire citation
  tags (`tools/upgrade_hub.py`).
- **Retrieval access layer (6-R.5).** New `docs/robots.txt` (allows Googlebot,
  Bingbot, OAI-SearchBot, GPTBot, PerplexityBot, ClaudeBot, Google-Extended +
  sitemap pointer), `docs/sitemap.xml` (hub + 28 chapters), `docs/llms.txt`
  (3.0 KB authority summary, < 5 KB limit, core/research/concepts/policies) and
  `docs/llms-full.txt` (full-volume digest) — all generated by
  `tools/build_site_infra.py`.

## Added — Governance

- **Cross-volume DOI registry (§2).** New `registry/cross_volume_doi.csv` and
  `.md` listing all 9 sibling white-papers with concept DOIs, latest-version
  DOIs, slugs and relations (`tools/build_registry.py`).
- **Irreproducibility ledger (Constitution C3).** New
  `IRREPRODUCIBILITY_LEDGER.md` aggregating every `[O]` item — `κ_opt = H₀/c`
  (open input), `κ` (single absolute anchor / four-wall), the absolute 150 Mpc
  acoustic length, the SN Hubble-diagram degeneracy with ΛCDM (χ²/dof 0.50 vs
  0.44), absolute CMB temperature, the D/a ratio, PPN β=1 and γ-ray dispersion —
  each with a reason and a canonical location (`tools/build_ledger.py`).
- **On-demand extractor (Constitution C2).** New `tools/extract.py` regenerates
  per-chapter text and LaTeX from the canonical HTML, so TeX/text SSOT need not
  be bundled in the distribution.

## Changed — Reproducibility (Constitution C1)

- **`docs/cosmology/_meta.json` reconciled to the manifest** (the authoritative
  post-v2.1 source). Chapter 7 counts corrected (words 2121→2265, eq_inline
  145→146, eq_display 7→8) and totals corrected (words 45172→45316, eq
  2385→2387); figures/tables already agreed (`tools/reconcile_meta.py`). The hub
  overview line was refreshed to the reconciled totals so displayed values match
  regenerated values.

## Distribution (Constitution C2)

- The distribution handoff **excludes** TeX/SSOT sources — `src/cosmology/*.tex`,
  `manifest/cosmology.eq_list.tsv` (base64 TeX), `tools/render_eq.js`,
  `tools/split.py` — which remain in the author's working repository. See
  `C2_PACKAGING.md`.

## Gate

- New `tools/gate_v1_8.py` validates the upgrade against §8 + C1/C2/C3 and
  writes `reports/phase-v1_8-cosmology.gate.json`.
- **Result: PASS — 24/24 hard checks.** The paragraph-length item is the spec's
  soft gate (advisory only; canonical prose is sealed and was not rewritten).

## Unchanged

- All canonical prose, equations (SVG + LaTeX alt), figures, tables, grades, and
  per-chapter source word counts. The volume's grading vocabulary
  (degenerate / distinguishing / conflicting) and no-tuning LOCK→derive→gate
  discipline are preserved.
