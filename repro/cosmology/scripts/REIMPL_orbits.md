# Re-implementation report: orbits group (ch4_orbits, ch5_mercury_capture, ch_spin_locking, ch10_post_newtonian)

Date: 2026-09-28. The original scripts were lost, so these four were rebuilt from what the site pages say each one did. They follow the conventions of `legacy_v2_3/`: a docstring with claim, inputs (with sources), algorithm and expected output; deterministic, with no random numbers (ensembles use a uniform phase grid); numpy only, with matplotlib optional under `MPLBACKEND=Agg`. Constants: the π-chain (`ν_H = 3π⁴+1`, `Q/M = ν_H/m_H`) comes from legacy `ch1_inflow_rates.py`. κ is fixed once by the Sun (`κ = GM☉/Q☉`, Ch 3). Masses, elements and radii are textbook values (JPL Standish Table 1, the IAU mass ratios, and the NASA fact sheets). Nothing was tuned to reach a page number. `docs/` was not edited. The equivalence principle is used as imported and is not re-derived.

Run: `cd repro/cosmology/scripts && MPLBACKEND=Agg python3 <script>.py`. Stdout from each run is saved as `<script>.log`.
Runtimes: ch4_orbits 15 s · ch5_mercury_capture 51 s · ch_spin_locking <1 s · ch10_post_newtonian 15 s.

## Summary of mismatches and flags
1. **ch4_orbits**: the page's ≤0.73 % is beaten (0.06 %) once correct JPL mean elements are used. The page's 0.73 % Saturn row is an input error in legacy `ch4_solar_system.py` (a = 9.582 AU). The "9.6e-12 scatter" and the "1.00001" are artefacts of the legacy integrator, not physics. Including planet masses (Q_p) improves Jupiter and Saturn. This is Newton-degenerate.
2. **ch5_mercury_capture**: 15.7 yr and the qualitative trends are reproduced. **The ≈7 % is the viscous (constant time-lag) result. The frequency-independent constant-Q model gives ≈77 %.** The page's attribution needs checking. The 55–73 % literature values and the "higher past e raises P" claim are not reproduced by this code.
3. **ch_spin_locking**: 12/12 is reproduced with a pre-registered textbook fiducial. Only 47 % of a broad fiducial grid gives 12/12, because Mercury's margin is only 0.5 dex. The dichotomy therefore depends on the fiducial band, which the page does not disclose.
4. **ch10_post_newtonian**: all numbers are reproduced (the Shapiro and GP-B values approximately). The result is GR-degenerate and conditional on γ = β = 1. β and frame-dragging stay open.
