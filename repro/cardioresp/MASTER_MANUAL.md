## 1. What this package is

A self-contained, offline-reproducible whitepaper showing that **heart (NKX2-5) and lung (NKX2-1) are
the same FitzHugh–Nagumo relaxation oscillator**, emerged from their measured master-gene stacking
stabilities (γ), differing only in the slow recovery time. From one cited time anchor the model derives
eupnea, the apnea / periodic-breathing threshold, respiratory sinus arrhythmia, the Cheyne–Stokes
period, and baroreflex regulation. A shared **R19 bistable-switch kernel** gives a carcinogen
dose–response with RR(0)=1, no threshold, and a convex shape. Every displayed quantity is graded
[F]/[V]/[L]/[O]; every number is regenerated by a deterministic engine.

The **firewall** (A1) is absolute: γ is a promoter stacking-stability read that fixes organ identity and
developmental order, **never** a clinical magnitude (heart rate, channel voltage, drug potency, dose,
incidence). The package asserts no therapy, dose, efficacy, or safety claim, and a fail-closed scanner
enforces this on every build.

## 2. Reproduce (one command, offline)

Requirements: Python 3 with `numpy` (standard library otherwise). No network needed.

```
python repro/run_all.py
```

Expected final line:

```
OVERALL: PASS (11/11 checks)   drift 0   DOI 10.5281/zenodo.20755371
```

The harness (a) emerges the organs from measured γ and confirms the shared oscillator, (b) runs the
T1–T5 stress battery and the carcinogen kernel, (c) runs the disease-extension battery, then (d) runs
the **reproducibility suite** R1–R11.

## 3. The reproducibility technology (inherited from analgesic_threshold_logic v2.0)

Inherited under the source package's concept DOI `10.5281/zenodo.20733420`. The apparatus is a
first-class deliverable (CONSTITUTION A6). The eleven gates:

| gate | module | checks |
|---|---|---|
| R1  | `gates.determinism` | two engine runs give an identical sha256 (`25900a90079a…`) |
| R2  | `gates.drift_ok` | the whole result blob (engine ⊕ stress ⊕ oncology ⊕ disease) is byte-identical across recomputation — **drift 0** |
| R3  | `stress_tests` | T1–T5 discriminants pass (5/5) |
| R4  | `_oncology` | carcinogen kernel: RR(0)=1, no threshold (LNT), barrier matches the R19 substrate |
| R5  | `_disease` | disease battery 6/6, every target reuses R19+FHN with no new primitive |
| R6  | `repro_manifest.verify` | every shipped file matches `manifest/SHA256SUMS.txt` (**fail-closed**) |
| R7  | `claim_scanner.scan` | no drug-dose / prescriptive / treatment / efficacy language on the site (fail-closed) |
| R8  | `doc_integrity.grades_ok` | only {[F],[V],[L],[O]} grade tokens appear |
| R9  | `doc_integrity.ledger_ok` | every site [O] has an obstacle in the ledger; open sections ⊆ ledger |
| R10 | `doc_integrity.doi_ok` | concept DOI embedded site-wide, no placeholder survives |
| R11 | `gates.offline_ok` | engine + stress reproduce with the network socket disabled |

**Fail-closed semantics.** R6 and R7 fail if their evidence is absent (empty/missing manifest;
unreadable docs), never silently pass. This is why a fresh checkout reports R6 FAIL until the manifest
is frozen.

## 4. Re-pinning after an intentional edit

The manifest is frozen as the **last** step of any release. After any deliberate change to a hashed
file (anything outside `reports/` and `zenodo/`):

```
python repro/_verify/repro_manifest.py freeze     # rewrites manifest/SHA256SUMS.txt
python repro/run_all.py                            # must show OVERALL: PASS (11/11), drift 0
```

Editing a hashed file **after** the freeze invalidates R6 — always freeze last.

## 5. Writing the canonical site (gated)

```
python tools/build_docs.py
```

`build_docs.py` refuses while `gates.writing_locked()` is True. Unlock requires all three: the research
gate green, `reports/research_complete.json` present, and `PHASE == writing`. The build is wall-clock
free (`RELEASE_DATE` pinned to `2026-06-18`), so regenerating the site reproduces it byte-for-byte.
Output is the canonical per-title HTML under `docs/` (VP-SPEC v1.8): answer-first pages, JSON-LD,
claim-strip carrying the live DOI, and `sitemap` / `robots` / `llms`.

## 6. Grading and the ledger

Four grades only: **[F]** forced by the R19 substrate · **[V]** reproduced and numerically checked ·
**[L]** anchored to a cited literature value · **[O]** open (needs external calibration). The package has
exactly **three [O] items** — absolute organ size (§1, §9), absolute cancer relative-risk magnitude
(§8, §9), and the absolute shared-substrate disease-spectrum magnitudes (§11) — each listed in
`IRREPRODUCIBILITY_LEDGER.md` with its obstacle, all tracing to the same un-calibrated switch noise scale
and stimulus→bias conversion. Their forced/verified counterparts (size *order*; dose–response *shape* and
the no-threshold endpoint; the reused dynamical mechanism) stand independently of the open absolute scale.
An [O] without an obstacle is a gate FAIL (R9).

## 7. Extending the package

The research roadmap is `FUTURE_WORK.md` (sections 0–7); the reproducibility-technology inheritance and
the sibling retroactive-application plan are §8. Rules when adding science:

- Add the result to the engine / stress / disease modules with its honest grade; nothing with an
  *anticipated* grade enters `docs/` (A4).
- No constant is chosen to hit a target (A3); discriminants pass under wide sweeps or not at all.
- If a new [O] appears, add its obstacle to the ledger in the same change (R9 will otherwise FAIL).
- Re-run `run_all.py`, then re-freeze the manifest last.
