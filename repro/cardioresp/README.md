# cardioresp_vp_site — v0.5.0

**Cardiorespiratory Emergence: Heart and Lung as Coupled Relaxation Oscillators under Reflex Control.**

A self-contained, offline-reproducible whitepaper in the jamming-physics idiom: heart (NKX2-5) and lung
(NKX2-1) are emerged from their measured master-gene stacking stabilities and shown to be the **same**
FitzHugh–Nagumo relaxation oscillator, differing only in the slow recovery time. From one cited time
anchor the model derives eupnea, the apnea (periodic-breathing) threshold, respiratory sinus arrhythmia,
the Cheyne–Stokes period, and baroreflex regulation; a shared R19 bistable-switch kernel gives a
carcinogen dose–response with RR(0)=1, no threshold, and a convex shape. Every claim is graded
[F]/[V]/[L]/[O] and every number is regenerated by a deterministic engine.

```
python repro/run_all.py        # -> OVERALL: PASS (11/11 checks), drift 0
```

stress battery and the carcinogen kernel, runs the disease-extension battery, and then runs the
**reproducibility suite** (the technology inherited from `analgesic_threshold_logic` v2.0,
