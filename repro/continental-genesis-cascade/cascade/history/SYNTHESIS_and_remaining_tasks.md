## 2. The remaining tasks (constructive — what completes the reconstruction)

### A. Verify the causal ORDERING without dating (the keystone next step)
The firewall caps absolute dates but NOT stratigraphic **superposition** — relative order is
present-tense. The cascade predicts a specific ORDER:
   flood signature  ->  glacial deposits  ->  meltwater/anoxic source bed  ->  oil migration
   ->  (rift/salt interleaved).
**Task:** assemble, basin by basin, the observed superposition of these units and test
whether the order matches the predicted causal sequence. If the order is systematically
wrong, the causal chain breaks (a real test). If it holds, the coupling gains its strongest
present-tense support. **This is the single most important remaining build** — it is exactly
"set the reconstruction, then check causality," and it is firewall-clean (order ≠ date).

### B. Map the spatial coupling on real geography (finish M41)
Overlay real ice-sheet extents (Laurentide, Fennoscandian, Patagonian) + meltwater routing
(continental slope) + actual source-basin / oil-field locations. **Task:** quantify the
overlap — do the source basins sit where the chain routes the meltwater (or in warm
restricted seas)? M41 did this with idealised latitude×type; this does it with the real map.

### C. Close the quantitative BUDGETS (the causal couplings, as numbers)
A coupled single event must balance at each link. Several are open:
1. **Reservoir energy -> ice volume:** does the released latent heat suffice to build the
   ice mass? (energy closure)
2. **Ice meltwater -> basin freshwater lid:** does the meltwater volume suffice to stratify
   the receiving basins to anoxia? (mass closure)
3. **Organic burial -> oil in place:** does source TOC x area x burial suffice for the known
   petroleum volumes? (carbon closure)
4. **Evaporite budget:** does the restricted-basin water/evaporation balance produce the
   salt-giant volumes in the same basins? (salt closure)
Each closure that holds tightens the reconstruction; each that fails localises a real gap.

### D. The one clean discriminator (still open)

independent-magnitude mainstream does not (spatial co-variation alone, SH-61, was shown
non-discriminating; a ratio is what's needed). This is the only test that could move a claim
off [O] toward [V]. Worth one serious attempt.

### E. Kernel consistency across the VP corpus
