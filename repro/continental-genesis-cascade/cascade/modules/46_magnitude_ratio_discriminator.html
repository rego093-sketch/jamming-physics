Module 46 — Magnitude-ratio discriminator (SH-26): the one genuinely-discriminating test, built and run

In plain terms. If one event really set the whole oil suite, then the ratios between its parts (salt vs stretch, source vs stretch, salt vs source) should be the same everywhere — a fixed recipe. If instead each part has its own cause (the mainstream view), those ratios should vary from place to place. Salt-vs-stretch is tied together in both pictures, so it can't decide. The deciding ratios — source-vs-stretch and salt-vs-source — come out in between: not fixed enough to prove one event, not varied enough to prove separate causes. So even this last test can't cleanly tell the two apart.

1. Why this module exists

Module 39 ended by naming the only test that could separate the cascade from the mainstream past the rate firewall: a genuinely discriminating version would need a magnitude RATIO the one-parameter budget predicts and independent-magnitude mainstream does not (the open C-2 candidate, SH-26) — still UNBUILT. This module builds it and runs it on the only internally-consistent frozen present-tense dataset available (the South Atlantic conjugate-margin segments, M39's data).

2. Why this is NOT the degenerate M39 co-variation

A single conserved relaxation (one parameter) would set the whole suite, so all pairwise magnitude ratios should be universal constants — low scatter. The mainstream treats the magnitudes as independent: salt is set by accommodation + restriction + arid climate; the source rock by productivity + anoxia. Different controls ⇒ the cross-control ratios should scatter.

Crucially, salt/extension is mechanical (more stretch → more accommodation → more salt) in both frameworks, so it is degenerate — M39 already showed it co-varies (r = +0.99). It is reported but is not the discriminator. The discriminator is the cross-control ratios source/extension and salt/source: tight ⇒ one-parameter; scattered ⇒ mainstream.

4. Honest caveats (load-bearing on the grade)

Three limits are stated up front, not after the result. (1) All six segments are one rift system (the South Atlantic opening), not independent realisations of different coupled events; a within-system ratio cannot be a universal-constant test. (2) Source magnitude is proxied by TOC (richness), not volume (thickness×area) — the frozen set has no source thickness, and the TOC column is coarse (three buckets). (3) n = 6.

5. The decisive version (specified, and why it stays [O]/unbuilt)

The decisive test is the same ratio across independent salt-giant systems — South Atlantic, Gulf of Mexico, Red Sea, Zechstein, Messinian, Pricaspian (the canonical population, so no cherry-picking) — with verified source-rock volumes. If the cross-control ratio is the same across these independent systems ⇒ a universal constant (strong one-parameter); if it varies by system ⇒ local control (mainstream). This run is UNRUN: it needs verified cross-system volumes, and fabricating those numbers would violate the framework (no unverified data, no fitting), so it is left [O]/unbuilt rather than guessed.

6. Grade and what it means for the cascade

The SH-26 discriminator is now built and specified, not merely named. The within-system run is [L]/inconclusive: salt/extension tight (degenerate), cross-control ratios intermediate. So SH-26 joins M37 (basal-character) and M39 (P5 co-variation) as a third present-tense axis that is degenerate between the frameworks. The honest standing is unchanged and now triply-demonstrated: no present-tense observable cleanly separates the cascade from the mainstream; the framework's edge remains coherence and parsimony, and absolute timing / occurrence stay [O], both directions. Falsification = discovery.
