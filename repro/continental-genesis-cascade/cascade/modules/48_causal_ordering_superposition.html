Module 48 — Causal-ordering / superposition test (SH-66): the SYNTHESIS "#1 build", built and run

In plain terms. You can't read the dates off the rocks without breaking the firewall — but you can read the order: which layer sits on top of which is a fact you see today. The cascade predicts a specific stacking order — the basin forms, then the source rock is laid down, then oil rises into the rock above it; and where there was ice, the glacial layer sits below the source rock. Across eight major oil basins that order holds every time (16 out of 16 checks). That's a real pass — if it had failed, the story would break. But here's the honest catch: the ordinary textbook account predicts the same order (you must bury a source rock before its oil can rise), so passing doesn't prove this story over that one. And the one place the strong version of the claim could have won — salt always in the same spot — fails: salt sits above the source in the Atlantic pre-salt but below it in the North Sea and Gulf of Mexico. So the order is real and consistent, but it can't tell the two frameworks apart.

1. Why this module exists

The SYNTHESIS & Remaining Tasks document was explicit: the firewall caps absolute dates but NOT stratigraphic superposition — relative order is present-tense ... this is the single most important remaining build. It is firewall-clean precisely because order is not a date: which unit sits below which is a fact one reads today, with no chronology imported. This module builds that test and runs it, so the program's own highest-priority item is no longer merely named.

2. The predicted order and the three forced relations

One coupled relaxation predicts a deposition order (deepest/earliest → shallowest/latest):

RIFT < GLACIAL < SOURCE < SALT < RES_OIL

Three of these relations are causally necessary — if the chain is real they must hold, and if they were violated basin-to-basin the chain would break:

relationwhy it is causally forced
RIFT < SOURCEthe basin must exist before it can be filled with an organic-rich bed
GLACIAL < SOURCEthe post-glacial meltwater lid → stratification → anoxia produces the source bed, so the glacial unit sits below it
SOURCE < RES_OILoil migrates upward only after the source rock is buried and matured

The FLOOD stage is deliberately excluded: calling a particular clastic unit a "flood deposit" is an interpretation, and importing it would contaminate a present-tense test. Only non-interpretive lithostratigraphic units (rift, glaciogenic diamictite, source shale, evaporite, reservoir) are used.

Decision rule declared before reading the data (not fitted): core relations are ORDER-CONSISTENT if concordance ≥ 0.90; the salt position is universal only if every basin carrying both salt and source agrees in sign. The chain's predicted order is not violated anywhere — a genuine pass of a test that could have failed.

4. The strong reading, tested — and refuted

If a single fixed coupled order were imprinted by one event, salt would sit in a universal position relative to the source rock. It does not:

basinsalt vs source
Santos / Campos / Kwanza (South Atlantic pre-salt)salt ABOVE source
Central Graben (North Sea, Zechstein)salt BELOW source
Gulf of Mexico (Louann)salt BELOW source

Salt position is NON-UNIVERSAL (above in 3, below in 2). The strong "one fixed coupled order" reading is therefore REFUTED [V]. Salt position is set by local setting — sag-phase evaporite capping a lacustrine source in the pre-salt, versus early-rift/drift evaporite beneath a later marine source elsewhere — which both frameworks accommodate. Falsification = discovery.

5. Discrimination verdict

The concordance is real and present-tense [V], but it is not a discriminator: the same three relations are forced by ordinary mainstream basin evolution (deposition→burial→migration; post-glacial transgressive anoxia is the textbook origin of the Silurian hot-shale source rocks themselves). And the one reading that could have separated the frameworks — a universal salt position — is refuted. So superposition joins basal-character (M37), GIA geometry (M35), deglacial pattern (M34), P5 co-variation (M39) and the magnitude ratio (M46) as a degenerate present-tense axis. This is exactly the structural prediction of Module 20 and the reason Module 47 moves the value criterion off single discriminators and onto tuning-free causal closure.

The honest consequence is twofold: the cascade survives a test that could have falsified it, and the SYNTHESIS document's hope that superposition would be the decisive build is itself corrected — order constrains, but it does not decide.
