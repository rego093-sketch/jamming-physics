Open Frontier — single source of truth for remaining tasks

In plain terms. Three different to-do lists had grown up across the package and they no longer agreed with each other. This page is the one authoritative status. It says plainly which questions are now closed, which were advanced (built but waiting on verified data), which are genuinely still open and worth building next, which the author is deliberately holding, and which are open by design — the dating questions the firewall keeps open on purpose, forever, and which are therefore not "to be solved." Where any older list disagrees with this page, this page wins; the older lists are kept unchanged for the record.

One line. After the v30 finalization, the program's frontier is small and precise: the causal-ordering test (Task A) is built and closed (M48), kernel consistency (Task E) is built and closed (M51), the one clean discriminator (SH-26) is protocol-built with its exact verified-data gap pinned (M46/M49), the reservoir bottleneck (SH-5) is localised to a release fraction (M50); what remains genuinely open are the real-geography overlap (Task B), the residual budget closures (Task C), and the SH-26 decisive run (pending verified volumes) — and the two formerly author-held items are now both done (the Tier-4 mainstream stress-test, M52; the B.5 ordering seam, M53).
