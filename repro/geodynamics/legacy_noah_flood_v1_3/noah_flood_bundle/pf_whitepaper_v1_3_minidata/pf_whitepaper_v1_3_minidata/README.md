# pf_whitepaper_v1_3_minidata (Mini Repro Bundle)

이 번들은 백서 v1.3의 재현을 위한 **최소 예시 데이터**와 스키마/코드북/QA/체크섬을 제공합니다.
실제 분석 파이프라인은 동일 스키마의 풀 데이터로 교체하면 그대로 동작합니다.

## 폴더
- data/: R6–R10 미니 CSV
- docs/: provenance, codebook, methods
- qa/: 간단 QA 리포트
- checksums/: sha256sum.txt

## 사용
- CSV 스키마는 docs/codebook.md 참조
- 파이프라인에 연결 시 파일 경로만 교체
