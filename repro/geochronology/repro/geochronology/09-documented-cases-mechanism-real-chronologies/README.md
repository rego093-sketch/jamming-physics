# Documented cases - the mechanism in real chronologies

`cases_catalogue.csv` is a machine-readable catalogue of published accuracy
failures attributable to foreign-material incorporation / open-system
behaviour, on both clocks and both directions of bias, each with its
age-independent screen or fix and a literature key. It is the source table
behind chapter 9 (Table: documented cases). Every row is a literature
datum, not a new measurement; see the keyed references on the hub page.
