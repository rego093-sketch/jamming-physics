## 2. Open `[GATE]` items — explicitly **not** C3 irreproducibility

This volume's grade vocabulary is paper-specific — `[LOCK]` / `[DERIVE]` / `[GATE]`
(→ `g-lock` / `g-derive` / `g-gate`), **not** the `[F]/[H]/[V]/[O]` set. The token that visually
maps to the open/`g-open` lane here is `[GATE]`, and it denotes an **unproven theorem named as a
falsification target** — a mathematical statement the work deliberately does *not* claim — **not** a
*measurement that cannot be reproduced*. These two senses must not be conflated:

- An `[O]` item is a **number that exists** but cannot be regenerated in-package (compute gate).
- A `[GATE]` item is a **proposition that is not yet proved**; "reproducing" it is not a matter of
  running a script, so it carries no `[O]` grade and is excluded from §1 by construction.

Both are recorded here for completeness and for auditor cross-reference to **§14 (Claims, Non-Claims,
Falsification)** and **§3 (Marginal Substrate)**, where each gate is stated in body text as a gate
"precisely so it can be attacked":
