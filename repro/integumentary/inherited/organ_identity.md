# Organ identity (CITED from DNA morphogenesis gene-clock)

The DNA package already EMERGES visceral / morphogenetic organ identity and developmental order from
measured master-gene γ, grade **[V]**. This package CITES that result; it does **not** re-derive organ
existence. γ values are MEASURED (NN-stacking ΔG37, SantaLucia 1998), read-only, never fitted. Masters
marked **TO-MEASURE** are named but not yet in the atlas — an honest research input to fetch via the
DNA `fetch_morpho_gamma` pipeline, not a fabricated number.

| master gene | organ | measured γ | physiological role (this package) |
|---|---|---|---|
| TP63 | epidermis | 1.3643 | stratified barrier: basal->cornified transit |
| KRT14 | keratinocyte | 1.4894 | keratin barrier mechanics / structural integrity |
| MITF | melanocyte | 1.3945 | melanin synthesis + UV photoprotection |
| EDAR | skin_appendage | 1.3696 | hair follicle / sweat gland (thermoregulation interface) |
| PRDM1 | sebaceous_gland | 1.3432 | sebaceous (holocrine) lineage master; pilosebaceous-duct sebum + infundibular keratinization (v0.6.0) |

> SSOT: organ identity + emergence order live in DNA. γ changes there and propagates here by
> re-vendoring — never edited locally. To-measure entries are fetched, then vendored.
>
> **PRDM1 (v0.6.0):** the sebaceous master was a TO-MEASURE entry; it was FETCHED via the same
> `fetch_morpho_gamma` NN-ΔG37 pipeline (NCBI exact TSS NC_000006.12 +, window TSS-2000..+500),
> its sequence cached in `organ_promoters.cache.json` so γ reproduces offline bit-for-bit, then
> vendored. γ=1.3432 is MEASURED, not fitted (the pipeline was validated to reproduce the prior
> MITF/EDAR values byte-for-byte). PRDM1 is the *lowest*-γ organ here → its functional spinodal is
> the lowest → an emergence-order PREDICTION (earliest of the five), graded by sign vs cited timing,
> not claimed as a fitted match. Identity master = Blimp1/PRDM1 (Horsley et&nbsp;al., *Cell* 2006).
